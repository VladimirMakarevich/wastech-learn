# Открытые решения по дизайну прототипа

Вопросы, которые остались после сборки экрана повторения в мире «Evening Glass» ([DESIGN.md](../../DESIGN.md)). У каждого — рекомендация; решение за владельцем. Когда вопрос закрыт, строка удаляется, а решение попадает в DESIGN.md или в код.

## Нужно решение

Открытых вопросов нет: владелец принял рекомендации по всем тринадцати.

## Что уже решено в этой сессии

- Мир задан словами владельца: свежий стиль по мотивам iOS, матовое стекло. Тёмная тема основная (повторение — вечером в тёмной комнате).
- Акцентный цвет — teal; красный только у «Не вспомнил».
- Стекло только у хрома, под которым прокручивается контент: тулбар, панель решения, таб-бар на телефоне, тост. Сайдбар непрозрачный.
- Схемы Mermaid встраиваются inline и красятся токенами темы; код подсвечивается в обеих темах.
- Шрифт вне Apple — Inter, лежит в `fonts/` (variable woff2: latin, latin-ext, cyrillic, лицензия OFL), без CDN.
- Поле точек памяти показывает карточки сессии. Оценённая точка всегда ярчает: сразу после повтора R = 1, оценка меняет только stability.
- Оценки меняют общие демо-данные до перезагрузки страницы; режим «После перерыва» без цветового сигнала.
- Подпись Hard короткая — «С трудом»; спецификация ([interaction.md](../../docs/ux/interaction.md)) поправлена под неё.
- Тип и уровень на чипе остаются английскими: это термины методики.
- Телефон: sheet инспектора и закреплённая панель решения — в мобильной сборке (phase 2).
- Порядок проработки экранов: главная → тема → карточки → статистика → настройки. Нейтральные чипы языков — на проходе главной.
- Кнопка «Показать ответ» в тёмной теме остаётся как есть; DESIGN.md остаётся справочником токенов сверх бюджета строк.
- Из `.impeccable/` коммитятся `design.json` и `surfaces/`; `review/`, `mocks/`, `questions/` и локальные файлы уже закрыты вложенными `.gitignore`.

- Экраны библиотеки (главная, темы, тема, карточки, статистика, настройки) собраны в «Evening Glass»: точки памяти везде, статистика — сгруппированные списки и одна подписанная диаграмма, настройки и фильтры — переключатель, степпер, слайдер, сегменты.
- На телефоне в таб-баре пять вкладок, настройки — значок в шапке рядом с языком и темой.
- Вопрос в карточке повторения стоит вверху, а не по центру: при показе ответа он не прыгает.

## Состояние ревью

Ревью экранов библиотеки (impeccable-finish-reviewer): первый вердикт `fix`, восемь замечаний. Два раунда проверки исправлений закрыли все, кроме найденной во втором раунде регрессии: таблицы на десктопе перестали растягиваться на ширину колонки. Её исправили после второго вердикта и проверили замером (на 1440 px таблицы во всю ширину статьи, на 390 px страница не шире экрана), но третьего вердикта не было. Не взяты «потолочные» улучшения ревьюера: крупные заголовки iOS, разделители с отступом, центрированная колонка настроек, подсказка значения на диаграмме, своё движение в библиотеке. `npm run lint` зелёный, у DESIGN.md остаются предупреждения о размере (176 строк, ошибка с 180).

Ничего не закоммичено. Предлагаемые коммиты:

1. `feat(prototype): design the library screens in Evening Glass` — `prototypes/desktop-ui/*`.
2. `docs: record the library components in DESIGN.md` — DESIGN.md, `.impeccable/design.json`, `.impeccable/surfaces/`.

## Как продолжить

Все экраны прототипа прошли дизайн. Следующий шаг по плану проекта — выбор UI-стека (Q-13, ADR-0006) по итогам прототипа, затем M2.

Прототип открывается файлом `index.html` или через локальный сервер:

```bash
python3 -m http.server 8766 --bind 127.0.0.1 --directory prototypes/desktop-ui
```
