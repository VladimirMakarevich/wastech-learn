# Прототип десктопного UI

Кликабельный прототип интерфейса для проверки компоновки и сценариев до выбора UI-стека ([Q-13](../../docs/risks-and-questions.md)). Написан на чистых HTML, CSS и JS без фреймворка: оценивается сам интерфейс, а не Ionic или Angular.

## Что внутри

| Экран | Что показывает | Требования |
| --- | --- | --- |
| Главная | «N карточек ≈ M мин», прогноз на 7 дней, темы; переключатель «После перерыва» показывает план возврата | FR-401 |
| Повторение | Вопрос → уверенность 1–3 → ответ со схемой → 4 оценки с интервалами; рубрика-чеклист у `scenario`; справа контекст темы и состояние FSRS | FR-202, FR-203, FR-209 |
| Итоги | Сколько вспомнил, ошибки при уверенности «точно», без стриков | FR-402 |
| Тема | Оглавление, summary с диаграммой и кодом, скрытый Self-check, pretest, карточки, материалы | FR-302, FR-303 |
| Карточки | Поиск, фильтры, таблица, превью карточки в боковой панели | FR-304, FR-305 |
| Статистика, Настройки | Демо-метрики; язык UI ru/en/pl, DR, лимиты, проверка голоса pl-PL | FR-403, FR-509, FR-504 |

Горячие клавиши в повторении: `Space`, `1`–`4`, `u`, `o`, `e`, `p`, `!`, `Esc` ([interaction.md](../../docs/ux/interaction.md)). На главной `Enter` запускает режим «5 минут».

Внешний вид следует миру «Evening Glass» из [DESIGN.md](../../DESIGN.md): тёмная тема основная, матовое стекло только у плавающего хрома, один акцентный цвет. Шрифт вне Apple — Inter из `fonts/` (лицензия OFL в `fonts/OFL.txt`), без CDN. Все экраны собраны в этом мире: повторение — по своему контракту, остальные — как библиотека из сгруппированных списков в стиле iOS с точками памяти вместо полосок. Вопросы к владельцу по дизайну собраны в [open-decisions.md](open-decisions.md).

Данные настоящие — golden sample из `wastech-learn-content`. Интервалы, R, stability и статистика — демонстрационные: FSRS здесь не считается.

## Запуск

Открыть `index.html` в браузере. Сборка не нужна, `data.js` уже лежит рядом.

Пересобрать данные после правок контента (рядом должен лежать `wastech-learn-content`):

```bash
npm run proto:data
```

`build-data.mjs` — упрощённый прообраз компилятора content bundle: front matter, Markdown → HTML через remark и GFM, подсветка Shiki, SVG-диаграммы встраиваются ([components.md](../../docs/architecture/components.md)).
