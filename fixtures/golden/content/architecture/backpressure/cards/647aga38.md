# Channels: TryWrite on a full channel

## Question

[C# Channels] What does the second `TryWrite` return here?

```csharp
var ch = Channel.CreateBounded<int>(1);
ch.Writer.TryWrite(1);
var ok = ch.Writer.TryWrite(2); // no reader yet
```

## Answer

`false`: the channel is full and `TryWrite` never waits.
