# Персона и сценарии

## Персона

**Senior-разработчик (Angular, .NET).** Изучает архитектуру, high-load и паттерны на английском, часть тем ему проще на русском. Параллельно учит польский. Темы разбирает в ИИ-чатах по подписке, без API-ключей. Основной чат — Claude Code, иногда ChatGPT. Повторяет нерегулярно: то каждый день, то раз в неделю. Контент правит в VS Code. Хорошо усваивает наглядное: схемы, таблицы сравнения, аннотированный код.

## J-01. Захват темы в Claude Code

1. Пользователь открывает Claude Code в `wastech-learn-content` и говорит: «разберём backpressure, домен architecture, на английском».
2. Skill `learn-capture` задаёт 3–5 pre-questions, к каждому пользователь отмечает уверенность. Ответы сохраняются в `index.md`.
3. Идёт сократический диалог ([тьютор](../ai/tutor-and-grading.md)). Тема знакомая (`familiarity: familiar`), поэтому сначала задача, потом объяснение.
4. Brain dump: пользователь своими словами формулирует ключевую идею, ИИ отмечает пробелы.
5. ИИ проверяет дубли через `search` и предлагает 8–15 кандидатов карточек. Пользователь отбирает и правит их.
6. ИИ сохраняет summary, материалы, диаграмму (Mermaid → SVG) и выбранные карточки через MCP. Каждая запись проходит `validate`.
7. Мини-квиз по 3 карточкам. Результаты записываются как learning step.

## J-02. Захват темы из ChatGPT

1. Тема разбирается в ChatGPT.
2. Пользователь вставляет универсальный промпт экспорта ([learning package](../ai/learning-package.md)). ChatGPT выдаёт один MD-файл.
3. Файл сохраняется в `inbox/`. В Claude Code запускается `learn-import`: он показывает кандидатов карточек на отбор, раскладывает пакет по файлам темы и валидирует.

## J-03. Повторение на десктопе

1. На главной: «23 карточки ≈ 6 мин».
2. В очереди вперемешку review items из разных тем.
3. По каждому: вопрос → попытка вспомнить → уверенность 1–3 → Space → ответ → оценка 1–4.
4. Из карточки можно открыть тему (`o`) или файл в VS Code (`e`).
5. На экране итогов — результат сессии, без стриков.

## J-04. Возврат после перерыва

1. После двух недель паузы на главной: «Накопилось 180 карточек ≈ 45 мин. Предлагаем разобрать за 3 дня по 15 мин».
2. Новые карточки автоматически на паузе.
3. Режим «5 минут» берёт review items с самой низкой R.
4. Новые карточки возвращаются, когда бэклог снижается ([backlog](../scheduling/backlog.md)).

## J-05. Польские слова и грамматика

1. В Claude Code: «добавь 10 слов по теме „w restauracji“». Получаются карточки `vocab` с примером предложения, родом и видом.
2. Каждая карточка даёт два review item: pl→ru и ru→pl. У языкового домена свой лимит новых карточек.
3. При повторении кнопка 🔊 озвучивает слово (Web Speech, `pl-PL`). Если голоса нет, кнопка скрыта.
4. Грамматика повторяется через `grammar-cloze`: «Nie mam {{c1::czasu}} (czas, D.)».

## J-06. Еженедельная смешанная сессия

Раз в неделю 20–30 минут сценарных карточек и карточек сравнения из разных доменов: «10k RPS, CPU БД 90% — первый шаг?». Тренирует выбор решения, а не узнавание (interleaving).

## J-07. Deep dive и починка leech

Раз в месяц пользователь открывает список leech и помеченных карточек. Каждую переписывает, разбивает, дополняет примером или мнемоникой, а заодно дополняет summary и открытые вопросы. По одному design-prompt пишет и рефлексию в журнал.

## J-08. Второй компьютер

1. `git pull` контент-репозитория, локальный сервер пересобирает кэш из журналов всех устройств.
2. Повторения на втором компьютере пишутся в свой файл `reviews/<device>/<writer>-YYYY-MM.jsonl`.
3. `git push` проходит без конфликтов ([sync](../architecture/sync.md)).

## J-09. Квиз в Claude Code

1. Пользователь пишет: «погоняй меня 10 минут». Skill `learn-quiz` получает due review items через MCP.
2. Простые карточки — самооценка. Для сценарной ИИ сверяет свободный ответ с рубрикой, объясняет пропуски и предлагает оценку.
3. Пользователь подтверждает или меняет оценку, событие пишется с `grader: ai`.
