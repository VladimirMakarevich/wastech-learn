# Типы карточек

Каталог типов для инженерных знаний и для польского языка. Тип пишется во front matter карточки (`type`), формат файла описан в [cards.md](../content/cards.md). В MVP шесть типов (колонка «Фаза»), остальные добавляются без изменения журнала: это новая схема и новый рендер ([NFR-06](../requirements/nfr.md)).

## Каталог

| `type` | Когда | Bloom | Варианты | Оценка | Фаза |
| --- | --- | --- | --- | --- | --- |
| `basic` | Термин, факт, «предскажи вывод кода» | remember / understand | `main` | self | MVP |
| `cloze` | Термин в контексте, шаг последовательности | remember | `c1`…`c3` | self | MVP |
| `reversed` | Связь нужна в обе стороны (паттерн ↔ назначение) | remember | `fwd`, `rev` | self | MVP |
| `why` | Механизм: «почему» и «как» | understand | `main` | self | MVP |
| `compare` | Trade-off, легко путаемые понятия | analyze | `main` | self | MVP |
| `scenario` | Применение и перенос: выбрать решение под условия | apply / evaluate | `main` | self по рубрике / ai | MVP |
| `vocab` | Слово польского ↔ перевод | remember | `fwd`, `rev` | self | MVP |
| `grammar-cloze` | Падеж, спряжение, вид глагола в предложении | apply | `c1`…`c3` | self | MVP |
| `design` | «Спроектируй X за 5 минут» | create | `main` | ai | Later |
| `bug` | Найди баг и назови исправление | analyze | `main` | self | Later |
| `explain` | «Объясни джуну за 3 предложения» | understand | `main` | ai | Later |
| `occlusion` | Скрытый блок на схеме | remember | `o1`…`oN` | self | Later |
| `draw` | Нарисуй схему сам, потом сравни | create | `main` | self по рубрике | Later |
| `salience` | «Где это пригодится в моей работе?» | apply | `main` | без оценки, редкий показ | Later |

## Примеры

| Тип | Вопрос | Ответ |
| --- | --- | --- |
| `basic` | [.NET GC] Какое поколение собирается чаще всего? | Gen 0 |
| `basic` (код) | [C# LINQ] `var q = list.Where(x => x > 2); list.Add(5);` Что вернёт `q.Count()` после добавления? | Учтёт 5: отложенное выполнение |
| `cloze` | [HTTP] Код `{{c1::429}}` означает Too Many Requests | Ограничение частоты (rate limit) |
| `reversed` | Паттерн, который превращает запрос в объект | Command |
| `why` | [Angular] Почему OnPush сокращает change detection? | Компонент проверяется только при новой ссылке в input, событии, async pipe или изменении signal |
| `compare` | [Распределённые транзакции] Saga или 2PC: что с доступностью? | У Saga нет глобальной блокировки, доступность выше; цена - eventual consistency |
| `scenario` | [High-load] 10k RPS на чтение, CPU БД 90%, данные меняются раз в минуту. Первый шаг? | Cache-aside с TTL ≈60 с, затем read replicas |
| `vocab` | rachunek | счёт (в ресторане), м. р. - *Poproszę rachunek.* |
| `grammar-cloze` | Nie mam `{{c1::czasu}}` (czas, D.) | Dopełniacz после отрицания |

## Как оценивать

Шкала - 4 кнопки ([srs.md](../scheduling/srs.md)):

- **Again** - не вспомнил или ошибся по сути.
- **Hard** - вспомнил с заметным усилием. Это зачёт.
- **Good** - вспомнил нормально.
- **Easy** - мгновенно и уверенно.

Правила для типов с рубрикой (`scenario`, `design`, `draw`):

- Названы все обязательные пункты рубрики → Good, а при усилии Hard.
- Не назван хотя бы один обязательный пункт → Again. Частичный ответ считается провалом, иначе оценки становятся непоследовательными.
- Easy - только если ответ полный и дан быстро.
- В вебе рубрика показывается чеклистом, и оценка предлагается по отмеченным пунктам. В чате пункты сверяет ИИ ([tutor-and-grading.md](../ai/tutor-and-grading.md)).

## Распределение по Bloom

У каждой карточки есть тег уровня (`bloom`). Карточек уровня `remember` должно быть не больше 40% в технических доменах: иначе колода тренирует узнавание фактов, а не понимание. Для `lang-pl` ограничения нет, там словарь - основа. Распределение показывается в аналитике (Later).

## Языковые карточки

- **`vocab`** - одна карточка даёт два review item: pl→ru (`fwd`) и ru→pl (`rev`). Обязательно пример предложения. Для существительных указывается род, для глаголов вид (dk/ndk).
- **`grammar-cloze`** - пропуск внутри реального предложения. Подсказка в скобках: начальная форма и падеж.
- **Озвучка** - кнопка TTS для текста на `pl` ([multilang.md](../content/multilang.md)).
- **Позже** - type-in answer для точной диакритики (ą, ę, ł, ż).
