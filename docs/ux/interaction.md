# Взаимодействие, тексты, i18n, доступность

## Горячие клавиши

| Клавиша | Где | Действие |
| --- | --- | --- |
| `Space` | Review | Показать ответ; после показа — Good |
| `1` `2` `3` | Review, до показа ответа | Уверенность: не уверен, скорее да, точно |
| `1` `2` `3` `4` | Review, после показа ответа | Again, Hard, Good, Easy |
| `u` / `Ctrl+Z` | Review, Session end | Отменить последнюю оценку; на итогах сессия открывается снова на этой карточке |
| `o` | Review, Browser | Открыть тему |
| `e` | Review, Browser, Topic | Открыть файл в VS Code (`vscode://file/<abs-path>:<line>`) |
| `r` | Review | Пометить «переписать» (Later, вместе с fix list) |
| `!` | Review | Отложить (suspend) |
| `b` | Review | Скрыть карточку до конца сессии, без записи в журнал |
| `p` | Review (`pl`) | Озвучить |
| `/` | Везде | Поиск |
| `g h` | Везде | На главную |
| `Esc` | Review | Закончить сессию и показать итоги |

Буквенные клавиши привязаны к физической клавише, а не к раскладке: в русской раскладке клавиша `u` печатает `г` и всё равно отменяет оценку. Латинские буквы с диакритикой (`ą`, `ę`) ничего не запускают.

## Подписи к оценкам

Под каждой кнопкой — короткая подпись и прогноз интервала ([ADR-0005](../adr/0005-four-button-rating.md)).

| Оценка | ru | en | pl |
| --- | --- | --- | --- |
| Again | Не вспомнил | Forgot | Nie pamiętam |
| Hard | С трудом | With effort | Z trudem |
| Good | Вспомнил | Recalled | Pamiętam |
| Easy | Легко | Easy | Łatwe |

Подписи короткие, чтобы четыре кнопки помещались в один ряд. Что Hard — это зачёт, объясняет подсказка при наведении: «Hard — это зачёт. Если не вспомнил, жми „Не вспомнил“».

## Тон текстов

Принцип: обучение без вины. Ошибки — нормальная часть процесса, а прогресс измеряется неделями.

| Не так | А так |
| --- | --- |
| «Вы пропустили 14 дней!» | «С возвращением! Накопилось 180 карточек ≈ 45 мин» |
| «Серия прервана» | (не показываем вообще) |
| «Неправильно» | «Не вспомнил — покажу позже» |
| «Вы ошиблись 5 раз» | «5 карточек стоит переформулировать» |
| «Осталось 300 карточек» | «На сегодня ≈ 15 мин, остальное подождёт» |

## i18n

- UI на ru, en и pl. Механизм и проверка паритета ключей берутся из `wastechlab-mobile-template`.
- Формы множественного числа CLDR (`one`, `few`, `many`, `other`): «1 карточка / 2 карточки / 5 карточек», «1 karta / 2 karty / 5 kart».
- Заголовки секций контента (`Question`, `TL;DR`) переводятся только при показе: в файлах они английские.
- Даты и числа форматируются через `Intl` по языку UI.
- Язык контента темы и язык UI независимы ([multilang](../content/multilang.md)).

## Доступность

- Повторение полностью проходится с клавиатуры, фокус всегда виден.
- Кнопки оценок — `button` с `aria-keyshortcuts` и полной подписью.
- Контраст не ниже WCAG AA. Цвет не единственный признак: у оценок есть и текст, и номер.
- `prefers-reduced-motion` отключает анимацию переворота карточки.
- У SVG-диаграмм есть alt-текст (CTX-005), а у сложных — текстовое описание в summary.

## Тёмная тема

Тёмная и светлая темы следуют настройке ОС. Shiki рендерит код в обеих темах через CSS-переменные, у SVG-диаграмм прозрачный фон и цвета `currentColor` (Q-10).
