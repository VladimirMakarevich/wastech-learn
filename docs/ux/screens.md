# Экраны

Текстовые wireframes экранов приложения. Кликабельная версия на данных golden sample — [прототип десктопного UI](../../prototypes/desktop-ui/README.md). Компоновка рассчитана на десктоп: широкая колонка для чтения и разделённые панели. Мобильная версия (Later) использует те же экраны в одну колонку ([ADR-0006](../adr/0006-headless-core-angular-ui.md)).

## Карта экранов

| Экран | Назначение | Фаза |
| --- | --- | --- |
| Home | Сколько повторять сегодня, вход в сессию, темы | MVP |
| Review | Повторение одного review item | MVP |
| Session end | Итоги сессии | MVP |
| Topic | Summary, материалы, карточки темы | MVP |
| Browser | Список карточек с поиском и фильтрами | MVP |
| Stats | Retention, прогноз нагрузки | MVP (минимум) |
| Settings | Язык UI, тема, длительность сессии; показ DR, лимитов и устройства | MVP |
| Fix list | Leech и помеченные карточки | Later |
| Cram | Тренировка по теме без влияния на расписание | Later |

## Home

```text
┌─────────────────────────────────────────────────────────────┐
│ wastech-learn                          🔍 поиск     ⚙  RU ▾ │
├─────────────────────────────────────────────────────────────┤
│  Сегодня: 23 карточки ≈ 6 мин                                │
│  [ 5 минут ]  [ 15 минут ]  [ Вся очередь ]                 │
│  Новые: 8 из 10 · lang-pl: 6 слов                            │
│                                                             │
│  Прогноз: Пн 23 · Вт 18 · Ср 31 · Чт 12 · Пт 20 · …          │
├─────────────────────────────────────────────────────────────┤
│  Темы                                                       │
│  architecture  ▸ backpressure (12 · due 3) ▸ cqrs (9)       │
│  dotnet        ▸ async-await (14 · due 5)                    │
│  lang-pl       ▸ w-restauracji (20 · due 7)                  │
└─────────────────────────────────────────────────────────────┘
```

После паузы больше 3 дней верхний блок меняется на план возврата ([backlog](../scheduling/backlog.md)). Темы в архиве в списке не показываются: под доменами — кнопка «Показать N тем в архиве».

**Индикатор синхронизации** внизу боковой панели на всех экранах: «desk1 · 2 оценки ждут сервер», «3 изменения не закоммичены», «синхронизация недоступна», «готово к отправке ↑1», «есть коммиты к получению ↓2» или «всё синхронизировано». Входящие коммиты видны после последнего fetch: сам индикатор сеть не открывает. Нажатие открывает **панель синхронизации** (модальный диалог): что войдёт в коммит (`content/`, `reviews/`, `inbox/`) и что не войдёт, поле сообщения с предложенным текстом, кнопки «Синхронизировать» и «Получить», строка итога или того, что делать дальше (файлы конфликта — ссылками в VS Code).

## Review

```text
┌──────────────────────────────── architecture / backpressure ┐
│  [Streaming] Why does a consumer signal demand to the        │
│  producer?                                                   │
│                                                              │
│  Уверенность:  ( 1 не уверен )  ( 2 скорее да )  ( 3 точно )  │
│                                                              │
│              [ Показать ответ — Space ]                       │
├──────────────────────────────────────────────────────────────┤
│  To keep the producer from overflowing the consumer buffer.  │
│  ┌ схема: Producer ──request(n)──▶ Consumer ┐                │
│                                                              │
│  [1 Не вспомнил]  [2 С трудом]  [3 Вспомнил]  [4 Легко]      │
│     <10 мин          2 дн          4 дн          9 дн         │
│  o тема · e в VS Code · u отменить · ! отложить · a в архив  │
└──────────────────────────────────────────────── 7 / 23 ─────┘
```

- Для `scenario` вместо одного ответа показывается рубрика-чеклист. Оценка предлагается по отмеченным пунктам.
- Для `vocab` на `pl` рядом с вопросом или ответом есть кнопка 🔊 (если голос доступен).
- Значок «изменена» появляется, если `contentHash` не совпадает с прошлым повторением.

## Session end

```text
  Готово: 23 карточки за 7 мин.
  Вспомнил 20 из 23 · ошибки при уверенности «точно»: 1 → [разобрать]
  Дальше: завтра ≈ 18 карточек.        [ На главную ]  [ Ещё 5 минут ]  [ u Отменить последнюю оценку ]
```

Если оценки сессии ещё не отправлены (журнал не закоммичен или коммит не запушен), под итогом — спокойная строка и кнопка «Синхронизировать». Стриков и «серий» нет. Оценка последней карточки сразу завершает сессию, поэтому отменить её можно здесь: сессия открывается снова на этой карточке.

## Topic

- Слева оглавление из 12 секций summary. В центре текст: диаграммы SVG, таблицы сравнения, подсвеченный код. Справа материалы и карточки темы (статус, R, due).
- `Self-check` закрыт: вопросы раскрываются по одному.
- Действия: «Повторить тему» (Later — cram), «Открыть в VS Code», «Тему в архив» / «Вернуть тему», «Связанные темы».
- Блок «Не закоммичено» справа: файлы темы (summary, материалы, диаграммы, карточки), которые отличаются от последнего коммита, с видом изменения.

## Browser

- Строка поиска (MiniSearch), фильтры: домен, тема, тип, статус (в том числе архив), `leech`, «изменена», «не закоммичено».
- Таблица: заголовок, тип, тема, R, due, lapses, последняя оценка; у карточки, отличной от коммита, — пометка «не закоммичено». Клик открывает просмотр карточки, `e` — VS Code.
- В просмотре: «В архив» или «Вернуть», «Удалить». Удаление карточки без истории — простое подтверждение; с историей — диалог объясняет, что история останется в журнале, и первым предлагает архив. Удалённые до коммита карточки — отдельной группой над таблицей с «Отменить удаление».
- Later: язык запросов как в Anki (FR-306).

## Stats

MVP: true retention (young и mature) за 7 и 30 дней, прогноз на 30 дней. Later: калибровка, Bloom, leech rate, mastery тем ([metrics](../scheduling/metrics.md)).

## Settings

Язык UI (ru, en, pl), тема и длительность короткой сессии — меняются здесь и хранятся в браузере. DR, лимиты по доменам и имя устройства только показываются: правка — в `learn.config.json` через VS Code. Проверка голоса TTS (`pl-PL`). Heatmap — Later.
