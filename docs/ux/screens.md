# Экраны

Текстовые wireframes экранов приложения. Кликабельная версия на данных golden sample — [прототип десктопного UI](../../prototypes/desktop-ui/README.md). Компоновка рассчитана на десктоп: широкая колонка для чтения и разделённые панели. Мобильная версия (Later) использует те же экраны в одну колонку ([ADR-0006](../adr/0006-headless-core-angular-ui.md)).

## Карта экранов

| Экран | Назначение | Фаза |
| --- | --- | --- |
| Home | Сколько повторять сегодня, вход в сессию, темы | MVP |
| Review | Повторение одного review item | MVP |
| Session end | Итоги сессии | MVP |
| Topic | Summary, материалы, карточки темы | MVP |
| Browser | Список карточек с поиском и фильтрами | MVP |
| Stats | Retention, прогноз нагрузки | MVP (минимум) |
| Settings | Язык UI, лимиты, DR, устройство | MVP |
| Fix list | Leech и помеченные карточки | Later |
| Cram | Тренировка по теме без влияния на расписание | Later |

## Review

```text
┌──────────────────────────────── architecture / backpressure ┐
│  [Streaming] Why does a consumer signal demand to the        │
│  producer?                                                   │
│                                                              │
│  Уверенность:  ( 1 не уверен )  ( 2 скорее да )  ( 3 точно )  │
│                                                              │
│              [ Показать ответ — Space ]                       │
├──────────────────────────────────────────────────────────────┤
│  To keep the producer from overflowing the consumer buffer.  │
│  ┌ схема: Producer ──request(n)──▶ Consumer ┐                │
│                                                              │
│  [1 Не вспомнил]  [2 С трудом]  [3 Вспомнил]  [4 Легко]      │
│     <10 мин          2 дн          4 дн          9 дн         │
│  o тема · e в VS Code · u отменить · ! отложить              │
└──────────────────────────────────────────────── 7 / 23 ─────┘
```

- Для `scenario` вместо одного ответа показывается рубрика-чеклист. Оценка предлагается по отмеченным пунктам.
- Для `vocab` на `pl` рядом с вопросом или ответом есть кнопка 🔊 (если голос доступен).
- Значок «изменена» появляется, если `contentHash` не совпадает с прошлым повторением.

## Session end

```text

  Вспомнил 20 из 23 · ошибки при уверенности «точно»: 1 → [разобрать]
  Дальше: завтра ≈ 18 карточек.        [ На главную ]  [ Ещё 5 минут ]
```

Стриков и «серий» нет.

## Topic

- Слева оглавление из 12 секций summary. В центре текст: диаграммы SVG, таблицы сравнения, подсвеченный код. Справа материалы и карточки темы (статус, R, due).
- `Self-check` закрыт: вопросы раскрываются по одному.
- Действия: «Повторить тему» (Later — cram), «Открыть в VS Code», «Связанные темы».

## Browser

- Строка поиска (MiniSearch), фильтры: домен, тема, тип, статус, `leech`, «изменена».
- Таблица: заголовок, тип, тема, R, due, lapses, последняя оценка. Клик открывает просмотр карточки, `e` — VS Code.
- Later: язык запросов как в Anki (FR-306).

## Stats

MVP: true retention (young и mature) за 7 и 30 дней, прогноз на 30 дней. Later: калибровка, Bloom, leech rate, mastery тем ([metrics](../scheduling/metrics.md)).

## Settings

Язык UI (ru, en, pl), DR, лимиты по доменам, длительность сессии, имя устройства, проверка голоса TTS (`pl-PL`), включение heatmap (по умолчанию выключен).
