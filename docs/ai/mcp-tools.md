# MCP-сервер `wastech-learn-mcp`

Тонкий хост над `core`, `srs` и `content-fs` без своей логики ([components](../architecture/components.md)). Транспорт — только stdio, для Claude Code и Codex. Сервер работает с одним контент-репозиторием из `--content`. Схемы входов — в `core`, разбор один раз, на границе.

## Принципы

- **Идемпотентность.** Клиенты MCP повторяют вызовы, поэтому каждый мутирующий инструмент принимает `requestId`. Повтор с тем же `requestId` и входом возвращает прежний ответ и ничего не пишет, в том числе после перезапуска. Тот же `requestId` с другим входом — ошибка `REQUEST_ID_REUSED`. Ответы хранятся в `.cache/mcp/requests.jsonl`: для записи контента сутки, для `record_review` и `undo_last` 10 минут — позже та же оценка считается новой, а не повтором. Вызов, который ничего не записал, не запоминается, и его можно повторить с тем же `requestId` после исправления; если запись прошла, а ответ не удалось сохранить, инструмент всё равно отвечает успехом. Записи одного репозитория идут по очереди, включая поиск по `requestId`.
- **Сначала валидация.** Любая запись проходит mdlint и `check` по репозиторию с наложенными новыми файлами: ссылки из `index.md` на карточки той же записи и якоря в summary разрешаются так же, как после записи. При ошибках ничего не пишется, а в ответе приходят находки. Ошибки, которые уже были в других файлах или в файле, который запись меняет попутно (`index.md` при `add_cards`), запись не блокируют. Текст секций во входе не может содержать заголовки `#`/`##` и строки, подчёркнутые `---` или `===`: они разбили бы секцию при чтении.
- **`dryRun`.** Сухой прогон даёт находки и будущие пути без записи; ему `requestId` не нужен, записи — обязателен.
- **Атомарность.** Файлы одного вызова пишутся целиком или не пишутся: временные файлы, резервные копии, переименования, откат при сбое.
- **Короткие ответы.** Возвращаются статус (`written`, `dry-run`, `blocked`), пути, id и находки, а не тексты файлов; находки одного правила в одном файле сворачиваются; ошибки приходят все, предупреждения — пока ответ не длиннее 12 строк. Исключения — `reveal` и `import_package`.
- **Только внутри `--content`.** Пути за пределами контент-репозитория отклоняются, включая `..`, абсолютные пути и символические ссылки наружу.
- **Язык.** Находки `check` и ошибки — из каталога `core` на `uiLanguage`; находки mdlint — его собственным текстом.

## Инструменты контента

| Инструмент | Вход | Выход | Побочные эффекты | Фаза |
| --- | --- | --- | --- | --- |
| `create_topic` | `domain`, `topic`, `title`, `lang`, `familiarity`, `keyIdea`, `pretest[]` (`question`, `answer?`, `confidence?`), `tags[]`, `related[]`, `origin` | тема, пути, находки | Создаёт `index.md`, а также пустые по шаблону `summary.md` и `materials.md` | MVP |
| `add_cards` | `topic`, `cards[]` (`title`, `type`, `bloom`, `grading`, `status`, `idea`, `tags`, `question`, `answer`, `rubric[]?`, `explanation?`, `sources[]`), `origin` | `ids[]`, пути, находки | Создаёт `cards/<id>.md`, дописывает ссылки в `## Cards` в `index.md` | MVP |
| `update_card` | `id`, `fields`, `meaningChanged` | id, `retired`, пути, находки | Правит файл; новый `title` обновляет и строку в `## Cards`; при `meaningChanged` старая карточка уходит в `retired`, новая получает новый `id` | MVP |
| `save_summary` | `topic`, `sections` (по именам шаблона), `status?`, `merge?` | путь, находки | Переписывает переданные секции, остальные оставляет; с `merge` заполняет только пустые секции, а новый текст непустых кладёт в `## Open questions`. Файл, который не читается как front matter плюс секции, не перезаписывается | MVP |
| `save_materials` | `topic`, `items[]` (`title`, `url`, `kind`, `why`, `status`) | путь, находки | Дописывает строки в таблицу; ссылка, которая уже есть, остаётся как есть | MVP |
| `save_diagram` | `topic`, `name`, `format: mermaid`, `source`, `alt` | пути `.mmd`/`.svg`, `embed` | Рендерит SVG (mermaid-cli) во временной папке, вписывает `source-sha256`, пишет оба файла | MVP |
| `validate` | `paths[]` и (или) `drafts[]` (`path`, `content`) | находки mdlint + `check` | — | MVP |
| `search` | `query`, `domain?`, `type?`, `status?`, `limit` | темы и карточки (id, заголовок, путь, сниппет) | — | MVP |
| `import_package` | путь в `inbox/` | разобранный пакет: тема, summary, материалы, диаграммы, кандидаты; `topicExists`; находки | — (запись идёт через инструменты выше) | MVP |
| `archive_package` | путь в `inbox/`, `requestId`, `dryRun` | откуда и куда | Переносит пакет в `inbox/done/` после отбора | MVP |

`save_diagram` с синтаксической ошибкой Mermaid отвечает находкой `diagram-render` с первой строкой ошибки и ничего не пишет; без `alt` — ошибка входа; рендер прерывается через 5 минут. `embed` — вставка `![alt](diagrams/<name>.svg)` для summary.

## Инструменты повторения

| Инструмент | Вход | Выход | Побочные эффекты | Фаза |
| --- | --- | --- | --- | --- |
| `queue_status` | — | due, новые, бэклог, оценка в минутах, длина сессии, домены с паузой новых | — | MVP |
| `quiz_next` | `limit` (≤10, по умолчанию 5), `scope?` (domain, topic, tag), `mode: review \| practice` | review items: вопрос (Markdown), тип, вариант, тема, язык; ни ответа, ни рубрики, ни объяснения | — | MVP |
| `reveal` | `item` | ответ, скрытые пропуски cloze, пример (обратная сторона vocab), рубрика, объяснение, `contentHash` | — | MVP |
| `record_review` | `item`, `rating`, `aiSuggested?`, `grader`, `confidence?`, `durMs?`, `mode`, `requestId` | следующий due, интервал, фаза, `lapses`, `suspended` | Дописывает событие в `reviews/<device>/mcp-YYYY-MM.jsonl`; оценка, на которой `lapses` достигают `leechThreshold`, дописывает и `suspend` — тем же вызовом | MVP |
| `undo_last` | `requestId` | отменённые события | Пишет `undo` для последней оценки с этого устройства и для `suspend`, который она вызвала | MVP |
| `suspend` / `unsuspend` | `item` | — | Пишет событие | Later |

`quiz_next` и `reveal` разделены, чтобы ИИ не видел ответ до попытки пользователя и не подсказывал раньше времени (LP-15). Заголовок карточки в `quiz_next` тоже не попадает: у слова в vocab он и есть ответ. Обратная сторона vocab спрашивается переводом без примера: пример содержит само слово и приходит в `reveal`. `scope` сужает уже построенную очередь дня, поэтому лимиты новых, пауза при бэклоге и разнесение siblings действуют и для области. `mode: practice` не двигает due.

## Ошибки

Неудачный вызов отвечает `{ code, message, hint }` (и `field` для ошибки входа) с флагом ошибки MCP. Находки валидации — не ошибка: они приходят в ответе со статусом `blocked`.

| Код | Когда |
| --- | --- |
| `INPUT_INVALID` | Вход не прошёл схему; `field` называет поле, `detail` — причину схемы по-английски |
| `TOOL_UNKNOWN` | Такого инструмента нет |
| `PATH_OUTSIDE_CONTENT` | Путь ведёт за пределы `--content` |
| `REQUEST_ID_REUSED` | Тот же `requestId` уже использован для другого вызова |
| `ITEM_NOT_ACTIVE` | `record_review` или `reveal` для review item без карточки; `record_review` для карточки не в статусе `active` |
| `TOPIC_EXISTS`, `TOPIC_NOT_FOUND`, `CARD_NOT_FOUND`, `PACKAGE_NOT_FOUND` | Тема уже есть, или нет того, к чему обращается вызов |
| `NOTHING_TO_UNDO` | Нет оценки с этого устройства, которую можно отменить |
| `CONTENT_CHANGED` | Файл сохранили, пока готовилась запись; ничего не записано, повтори вызов |
| `CONFIG_INVALID`, `REPOSITORY_NOT_FOUND`, `IO_FAILED`, `SCHEDULER_UNSUPPORTED`, `UNEXPECTED` | Операционные сбои; ничего не записано |

## Ресурсы и промпты MCP (Later)

Ресурсы `learn://topic/<domain>/<topic>/summary` и `learn://stats` — чтение без вызова инструментов; промпты `capture` и `quiz` — те же сценарии для клиентов без skills.

## MCP Apps (Later)

MCP Apps (с 2026-01; Claude, ChatGPT, VS Code): карточка с кнопками оценки и шкалой уверенности прямо в чате — в локальном клиенте, который их поддерживает.

## Безопасность

- В MVP нет сети: stdio и локальные файлы; контрактные тесты идут с отключёнными сокетами и `fetch`. Инструменты не выполняют пользовательский код и не открывают внешние URL.
- Remote-режима нет ([ADR-0016](../adr/0016-local-only.md)).
