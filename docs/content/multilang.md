# Мультиязычность

Пользователь учит архитектуру и паттерны на английском, некоторые темы ему проще на русском, и параллельно он изучает польский. Отсюда два независимых измерения: **язык контента темы** и **язык интерфейса**. Решение принято в [ADR-0011](../adr/0011-language-per-topic.md).

## Язык темы

- `lang` в `index.md` темы — `en`, `ru` или `pl`. Summary, материалы и карточки пишутся на этом языке.
- Термины остаются в оригинале на любом языке: CQRS, backpressure, change detection.
- Заголовки секций — фиксированные английские ключи (`## Question`, `## TL;DR`). Это нужно для SEC-001 и парсера, UI показывает их в переводе.
- Отдельная карточка может переопределить язык (`lang` во front matter). Это редкий случай.
- Тьютор говорит на языке пользователя, а артефакты пишет на языке темы.

## Язык интерфейса

- UI на ru, en и pl, переключается в настройках (`uiLanguage`).
- Используются формы множественного числа CLDR: в польском и русском их три (`one`, `few`, `many`), например «5 карточек», «5 kart», «5 cards».
- Ключи переводов проверяются на паритет между языками в CI. Механизм уже есть в `wastechlab-mobile-template` (NFR-10).

## Изучение польского

| Что | Как |
| --- | --- |
| Домен | `content/lang-pl/<topic>/`, темы по ситуациям (`w-restauracji`) и по грамматике (`dopelniacz`) |
| Словарь | Тип `vocab`, `langPair: pl-ru`. Варианты `fwd` (pl→ru) и `rev` (ru→pl). Обязателен пример предложения, для существительных — род, для глаголов — вид |
| Грамматика | Тип `grammar-cloze`: пропуск в реальном предложении с подсказкой (начальная форма, падеж) |
| Summary | Языковой шаблон: `TL;DR`, `Rules`, `Examples`, `Exceptions`, `Comparison` (например, таблица склонения), `Self-check`, `Related`, `Sources` |
| Лимиты | Свой лимит новых карточек: 10 слов в день = 20 review items. Языковые карточки не вытесняют технические |
| Озвучка (MVP) | Web Speech API, голос `pl-PL`. Кнопка 🔊 появляется, только если голос установлен |
| Озвучка (Later) | Piper — офлайн-нейро-TTS с польскими голосами. Генерирует `audio/<id>.opus` (~20 KB), работает и на мобильном, ключи не нужны |
| Ввод ответа (Later) | Type-in answer с проверкой диакритики (ą, ć, ę, ł, ń, ó, ś, ź, ż) |
| Произношение | Оценки произношения нет: распознавание речи в браузере отправляет аудио третьим лицам (non-goal) |

Голоса Web Speech зависят от ОС и браузера. На Linux в Chromium с espeak качество низкое, офлайн голоса может не быть (R-07).

## Переводы (Later)

Если тему понадобится читать на другом языке:

- Перевод summary кладётся рядом: `summary.<lang>.md`. Так уже сделано в `wastime-app-content`.
- Перевод карточки — секции `## Question@ru` / `## Answer@ru` в том же файле. Прогресс общий, потому что `id` один. Формат вынесен в [Q-06](../risks-and-questions.md).
- Переводит ИИ в чате, пользователь проверяет. Перевод не должен менять смысл, иначе это новая карточка.

## Влияние на ограничения mdlint

- Кириллица весит в UTF-8 2 байта на символ, а оценка токенов `chars/4` её занижает в 2–3 раза. Поэтому для контента основная метрика — `bytes` ([mdlint-policy](../quality/mdlint-policy.md)).
- Лимиты в словах (`check`) одинаковы для всех языков. Польские и русские слова длиннее английских, поэтому лимиты в символах для них мягче на 20% (Q-07).
