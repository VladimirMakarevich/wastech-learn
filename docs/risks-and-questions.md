# Риски и открытые вопросы

Живой документ. Закрытый вопрос получает ссылку на ADR или документ, где принято решение.

## Риски

| ID | Риск | Вероятность | Влияние | Митигация |
| --- | --- | --- | --- | --- |
| R-01 | Ломающие изменения ts-fsrs (6.x уже сменила API и модель по умолчанию) | высокая | среднее | Точная версия, адаптер в `srs`, версия планировщика в событии, проверка replay на golden-журнале при обновлении |
| R-02 | Node ≥24 обязателен (ts-fsrs 6, wastech-mdlint) | средняя | низкое | `.nvmrc`, `engines`, проверка в CI |
| R-03 | Оценка токенов в mdlint (`chars/4`) занижает кириллицу в 2–3 раза | высокая | среднее | Для ru и pl основная метрика — `bytes`; `AGENTS.md` на английском |
| R-04 | Лимиты подписки: длинный захват и квиз тратят сообщения | средняя | среднее | Короткие ответы MCP, квиз батчами по 5–10, повторение в приложении без ИИ |
| R-05 | MCP в ChatGPT доступен не на всех тарифах, документация противоречива | средняя | низкое | Базовый путь — learning package; remote MCP только в фазе 2 |
| R-06 | `mermaid-cli` тянет headless Chromium: тяжёлая установка MCP-сервера | средняя | низкое | Ленивая установка рендера; запасной путь — Kroki в Docker |
| R-07 | Голоса Web Speech для `pl-PL` на Linux низкого качества или отсутствуют офлайн | высокая | низкое | Кнопка скрывается без голоса; Piper в фазе 3 |
| R-08 | iOS очищает хранилище PWA | средняя | высокое (фаза 2) | Нативная оболочка Capacitor + SQLite, git остаётся источником истины |
| R-09 | ИИ генерирует много слабых карточек, колода разрастается | высокая | высокое | Отбор пользователем, лимиты, поиск дублей, правило «меньше 5 хороших — ничего», метрика переписанных карточек |
| R-10 | Нерегулярный ритм превращается в отказ от системы | средняя | высокое | Режим «5 минут», план возврата, пауза новых карточек, никаких стриков |
| R-11 | Перенос Evening Glass в Angular и мобильные компоненты фазы 2 (sheet, закреплённая панель, жесты) займут больше, чем ожидается | средняя | среднее | Ограничить MVP-экраны; стили и токены берутся из прототипа; в фазе 2 точечно `@ionic/core`; ядро не зависит от UI. В M4 стили прототипа перенесены почти как есть, экраны собраны из его разметки; остаётся мобильная часть фазы 2 |
| R-12 | Расхождение пресета mdlint между фреймворком и контентом | средняя | низкое | Каноничный пресет в `core`, `check` предупреждает о пропавшем или изменённом правиле копии (Q-04) |
