## Критерии приёмки MVP

- Golden sample компилируется без ошибок. Страница темы показывает все 12 секций, диаграмму и подсвеченный код.
- После правки карточки в VS Code изменения видны в приложении меньше чем через 2 с (локальный режим).
- Два устройства, которые повторяли параллельно, после `git pull` и `git push` сходятся без конфликтов.
