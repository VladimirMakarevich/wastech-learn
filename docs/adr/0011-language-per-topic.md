# ADR-0011: Язык задаётся на тему, ключи секций на английском

## Контекст

Пользователь изучает темы на en, ru и pl, а польский ещё и как предмет. UI нужен на трёх языках. mdlint SEC-001 сравнивает заголовки секций точно, и парсер ядра опирается на те же заголовки.

## Решение

- `lang` (`en`/`ru`/`pl`) задаётся в `index.md` темы, весь контент темы пишется на нём. Карточка может переопределить язык, это редкий случай.
- Заголовки секций - фиксированные английские ключи (`Question`, `TL;DR`), UI показывает их в переводе.
- UI локализован на ru, en и pl с плюральными формами CLDR и проверкой паритета ключей.
- У языковых карточек есть `langPair` (`pl-ru`). У языкового домена свои лимиты новых карточек.
- Переводов в MVP нет. Позже: `summary.<lang>.md` и секции `@<lang>` у карточек (Q-06).

## Альтернативы

- **Каждая тема сразу на всех языках.** Втрое больше файлов, переводы рассинхронизируются, правка смысла требует правки в трёх местах.
- **Заголовки секций на языке темы.** Три набора правил SEC-001 и хрупкий парсер.

## Последствия

- Простая модель: один язык - один набор файлов.
- Чтобы читать тему на другом языке, нужен перевод (Later).
- Лимиты в символах для ru и pl мягче, а основная метрика размера - байты (Q-07).
