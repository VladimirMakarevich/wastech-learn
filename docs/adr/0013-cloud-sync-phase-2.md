# ADR-0013: Фаза 2 — Cloudflare Worker + D1 + Access, git остаётся архивом

## Контекст

Чтобы повторять с телефона и подключить remote MCP для claude.ai и ChatGPT, нужен сервер, доступный из интернета, но приватный. Пользователь один, бюджет минимальный, ритм нерегулярный: бесплатные проекты, которые засыпают, не подходят.

## Решение

- Content bundle публикуется в Cloudflare Pages, всё закрыто Cloudflare Access (бесплатно до 50 пользователей).
- Worker принимает события (идемпотентно по `event.id`) и складывает их в D1 (append-only). Он же отдаёт события с курсором `since`.
- Мобильное приложение (Capacitor) копит события в SQLite outbox и отправляет при появлении сети.
- `wastech-learn sync` на десктопе выгружает события из D1 в `reviews/<device>/*.jsonl` и коммитит их. Источник истины остаётся в git.
- Тот же Worker отдаёт remote MCP (OAuth). Запись контента — через ветку или PR в GitHub.

## Альтернативы

- **Supabase Free** — пауза после недели неактивности.
- **Turso sync** — офлайн-записи в бете, будущее неясно.
- **VPS** — требует обслуживания, платный.
- **isomorphic-git на телефоне** — нестабильно, без SSH.

## Последствия

- Статус `proposed`: решение окончательно принимается перед стартом фазы 2.
- Нужны OAuth для remote MCP и ревью безопасности (NFR-17).
- Лимиты бесплатного D1 (5 млн чтений и 100 тыс. записей строк в день) покрывают одного пользователя с большим запасом.
