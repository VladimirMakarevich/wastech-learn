# ADR-0009: ИИ предлагает оценку, пользователь подтверждает

## Контекст

Простые карточки оцениваются самостоятельно. Для открытых и сценарных пользователь хочет оценку от ИИ. Но LLM ошибаются в оценке, а самооценка тренирует калибровку (LP-08). API-ключей нет, поэтому ИИ доступен только в чате.

## Решение

- В чате (`learn-quiz`) ИИ раскладывает ответ по рубрике, предлагает оценку и объясняет её. **Финальную оценку подтверждает пользователь.**
- В событие пишутся обе: `rating` (финальная) и `aiSuggested`, плюс `grader: ai:<client>`.
- В вебе ИИ нет: рубрика показывается чеклистом, оценка предлагается по отмеченным пунктам.
- Грейдер — подключаемый интерфейс в ядре (`chat` сейчас; `claude-cli` и `api` позже).

## Альтернативы

- **Оценка ИИ окончательна.** Быстрее, но ошибки ИИ портят расписание, и теряется тренировка калибровки.
- **Только самооценка.** Это противоречит решению пользователя. Для сценариев полезна внешняя сверка с рубрикой.

## Последствия

- Расхождения `rating` и `aiSuggested` — полезная метрика: где ИИ или пользователь систематически ошибаются (Later).
- Открытые карточки в вебе можно отложить на ИИ-проверку в чате (тег `ai-check`, Later).
