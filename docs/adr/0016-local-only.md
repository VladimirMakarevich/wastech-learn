# ADR-0016: Только локальный запуск на компьютере - без облака и мобильной версии

## Контекст

По плану фаза 2 добавляла облако (Cloudflare Pages, Worker, D1, Access - [ADR-0013](0013-cloud-sync-phase-2.md)), remote MCP для чатов в браузере и мобильное приложение на Capacitor. После M4 владелец решил: система работает только на его компьютере, облако и телефон ему не нужны. Локальные клиенты с MCP (Claude Code, Codex в приложении ChatGPT) уже покрывают захват, а приложение на `127.0.0.1` - повторение.

## Решение

- Всё работает локально: `wastech-learn serve`, stdio MCP и CLI на компьютере владельца. Сервисов в интернете нет.
- Вне скоупа: облачное хранилище и синхронизация через сервер, remote MCP, мобильное приложение и пуш-напоминания. ADR-0013 отклонён, фаза 2 из roadmap убрана.
- Несколько компьютеров синхронизируются как сейчас - через git ([sync](../architecture/sync.md)).
- Чаты в браузере без MCP подключаются через learning package и `learn-import`.

## Альтернативы

- **Оставить фазу 2 в Later.** Документы и правила продолжали бы описывать облако, OAuth и Capacitor, которых не будет.
- **Только мобильная версия без облака** (синхронизация с компьютером по локальной сети или через git на телефоне). Владельцу не нужна; git на телефоне уже отвергнут в [sync](../architecture/sync.md).

## Последствия

- Требования FR-112, FR-410 и NFR-17 - `dropped`; NFR-15 сводится к раскладке от 360 px и `ReviewStore` без сборки под Capacitor.
- `ReviewStore` и content bundle остаются: они держат UI независимым от файлов и сервера, это нужно и без облака.
- Часть [ADR-0006](0006-headless-core-angular-ui.md) про Capacitor в фазе 2 больше не действует; выбор Angular + CDK остаётся.
- Если облако или телефон понадобятся, нужен новый ADR.
