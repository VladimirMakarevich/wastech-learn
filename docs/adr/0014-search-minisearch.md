# ADR-0014: Поиск - MiniSearch по content bundle

## Контекст

Нужен поиск по темам и карточкам в приложении (офлайн, в том числе на мобильном) и в MCP `search` для поиска дублей при захвате. Корпус небольшой: сотни тем и тысячи карточек. Поиск должен работать на ru, en и pl.

## Решение

- Один индекс MiniSearch строится при `build` по темам (title, TL;DR, секции summary) и по карточкам (вопрос, ответ, теги). Индекс сериализуется в content bundle.
- Фильтры по полям (домен, тип, статус, теги) применяются поверх результатов.
- MCP `search` использует тот же индекс на Node, так что поиск дублей и поиск в UI дают одинаковые результаты.
- Для польского и русского используется простая нормализация: нижний регистр, снятие диакритики для pl в дополнительном поле. Стемминг - позже (Q-12).

## Альтернативы

- **Pagefind** - отлично подходит статическим сайтам, но индекс публичный, нужен отдельный индекс для карточек, а на Node и в MCP он неудобен.
- **Orama** - мощнее, но для такого корпуса избыточен.
- **FlexSearch** - низкоуровневый, больше ручной работы.

## Последствия

- Поиск дублей лексический. Семантическую похожесть (переформулированный вопрос) оценивает ИИ в чате на основе списка кандидатов из поиска.
- Индекс пересобирается при каждом `build`. Для тысяч карточек это доли секунды.
