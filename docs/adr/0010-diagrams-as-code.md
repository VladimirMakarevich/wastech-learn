# ADR-0010: Диаграммы как код - источник + закоммиченный SVG

## Контекст

Визуал - ключевая часть обучения (LP-12). Схемы делает ИИ в чате. Они должны правиться текстом, нормально выглядеть в diff, отображаться в GitHub, VS Code и в приложении и проверяться mdlint (REF-003, CTX-005).

## Решение

- Источник `diagrams/<name>.mmd` (Mermaid в MVP; позже D2 и Excalidraw) и рядом отрендеренный `diagrams/<name>.svg`.
- SVG коммитится. Внутри него комментарий `source-sha256`, и `check` по нему ловит устаревший рендер.
- Рендер - `@mermaid-js/mermaid-cli` в MCP `save_diagram` и в CI.
- Markdown ссылается на SVG с обязательным alt-текстом. PNG делается только по необходимости (экспорт, Anki).

## Альтернативы

- **Только рендер в рантайме (Mermaid в браузере).** Схему не видно без приложения, REF-003 нечего проверять, рендер медленный на мобильном.
- **Только PNG.** Не правится, плохо масштабируется, тяжёлый diff.
- **Kroki-сервер для всех форматов.** Docker-зависимость в MVP не нужна, понадобится для D2 и Excalidraw позже.

## Последствия

- `mermaid-cli` тянет headless Chromium: тяжёлая зависимость для MCP-сервера (R-06).
- Схема и источник могут разойтись при ручной правке SVG. Это ловит `check`.
