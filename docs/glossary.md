# Глоссарий

Канонические термины проекта. В колонке `Aliases` перечислены нежелательные синонимы. Правило CTX-003 подсвечивает их в документах и предлагает канонический термин. Английские термины пишутся как есть, без перевода.

## Контент

| Term | Aliases | Определение |
| --- | --- | --- |
| домен | | Крупная область знаний, папка `content/<domain>/`: `architecture`, `dotnet`, `angular`, `lang-pl` |
| тема | | Единица изучения внутри домена: папка `content/<domain>/<topic>/` с `index.md`, `summary.md`, `materials.md`, `cards/`, `diagrams/` |
| карточка | флешкарта, флеш-карта, flashcard | Файл `cards/<id>.md` с вопросом и ответом. Хранит только контент, состояние повторения в ней нет |
| вариант | | Направление или пропуск внутри карточки: `main`, `fwd`, `rev`, `c1`…`c3` |
| review item | | То, что планирует FSRS: пара «карточка + вариант», записывается как `<id>:<variant>` |
| idea | | Одна мысль темы. На одну idea приходится 2–3 карточки с разных сторон (varied practice) |
| summary | конспект | Файл `summary.md` темы, оформленный по шаблону из 12 секций |
| материалы | | Файл `materials.md`: ссылки для углубления с пометкой, зачем читать |
| диаграмма | | Источник `.mmd` плюс отрендеренный `.svg` в `diagrams/` темы |
| learning package | | Один MD-файл с темой, который экспортирует чат без MCP. Попадает в `inbox/`, оттуда импортируется командой `learn-import` |
| golden sample | | Эталонный набор контента для тестов и онбординга |

## Повторение

| Term | Aliases | Определение |
| --- | --- | --- |
| FSRS | | Free Spaced Repetition Scheduler — алгоритм планирования, который предсказывает вероятность вспомнить |
| SM-2 | SM2 | Старый алгоритм Anki на основе ease factor. Отвергнут ([ADR-0004](adr/0004-fsrs-via-ts-fsrs.md)) |
| retrievability | | R — вероятность вспомнить review item прямо сейчас |
| stability | | S — за сколько дней R падает со 100% до 90% |
| difficulty | | D — сложность review item по шкале 1–10 |
| desired retention | | DR — целевая вероятность вспомнить в момент повторения. По умолчанию 0.90 |
| оценка | | Again / Hard / Good / Easy (1–4). Hard — это зачёт «с трудом», а не провал |
| lapse | | Провал (Again) у review item в состоянии Review |
| leech | | Review item с 8 и более lapses. Его приостанавливают и отправляют на переписывание |
| бэклог | | Просроченные review items, которые накопились после перерыва |
| bury | | Отложить review item до завтра. Применяется к соседним вариантам той же карточки |
| suspend | | Исключить review item из очереди до ручного возврата |
| событие | | Строка журнала `reviews/**.jsonl`: review, practice, reset, suspend, unsuspend, undo, manual_due |
| replay | | Пересчёт состояния всех review items прогоном журнала событий через планировщик |
| true retention | | Доля зачётов (Hard/Good/Easy) среди повторений в состоянии Review |

## Статусы и режимы

| Term | Aliases | Определение |
| --- | --- | --- |
| draft | | Карточка-кандидат: сохранена, но в очередь не попадает |
| active | | Карточка в очереди повторения |
| retired | | Карточка выведена навсегда. Файл и история сохраняются, `id` не переиспользуется |
| режим «5 минут» | | Сессия, ограниченная по времени. Выбирает самые «горящие» review items |
| cram | | Тренировка по теме или тегу без влияния на расписание (событие `practice`) |
| quiz | | Повторение внутри чата: ИИ задаёт вопросы и предлагает оценку, пользователь её подтверждает |
| рубрика | | Чеклист обязательных пунктов ответа для открытых и сценарных карточек |
| лестница подсказок | | Подсказки ИИ-тьютора по нарастающей, уровни H0–H4 |

## Система

| Term | Aliases | Определение |
| --- | --- | --- |
| content bundle | | Результат компиляции контент-репозитория: JSON-манифест, пререндеренный HTML, ассеты |
| ReviewStore | | Интерфейс хранения событий, через который UI работает с состоянием |
| writer | | Процесс, который дописывает события: `web`, `mcp`, `cli`. У каждого writer свой файл журнала |
| headless core | | Пакеты `core`, `srs` и `content-fs`, в которых вся логика. Хосты над ними тонкие |
