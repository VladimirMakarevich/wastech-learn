| AS-Q4 | Когда оценки считаются «не отправленными» для AS-F10 | Когда в состоянии git есть незакоммиченные пути `reviews/` или `ahead > 0` | 2026-11-27 |
| AS-Q5 | Какая клавиша для архива на Review | `a`, без подтверждения, с «Вернуть» в тосте; `!` остаётся «отложить» (design D13) | 2026-11-27 |
| AS-Q7 | Что говорить, если в контент-репозитории не заданы `user.name` и `user.email` | Отдельный код `identity-missing`; приложение называет команду `git config user.name` и `user.email` (фаза 01) | 2026-11-27 |
| AS-Q8 | Где тексты ошибок `git-*` и `card-*`: в каталоге `core` (план фазы 01) или приложения (design D12) | Коды и схемы ответов — в `core/schema/app.ts`, общие для сервера и приложения; тексты — в каталоге приложения: их показывает только оно, и там же тесты паритета, литералов и тона (AC-F15). Каталог `core` остаётся за CLI и MCP | 2026-11-27 |
| AS-Q9 | Отдельный код `no-upstream` у синхронизации или причина блокировки | Причина `blocked.reason` (нет upstream, detached HEAD, идущая операция, нет git) в одной форме `blocked: { reason }` в `GET /api/git` и в ответе `POST` с кодом `blocked` | 2026-11-27 |
| AS-Q10 | Как отличить «нет сети» от «нужен пароль» | Отдельный код `offline` по фразам ssh и git о недоступном хосте; `auth-required` и таймаут считаются только у команд, которые ходят к удалённому | 2026-11-27 |
| AS-Q11 | Что откатывать, если сбой после pull | Сбой до конца pull возвращает коммит и индекс к состоянию до нажатия. После pull откат превратил бы полученные коммиты в правки рабочего дерева, поэтому сбой push и правки, оставшиеся в stash, сохраняют локальный коммит до следующей синхронизации; AC-N02b для них не действует | 2026-11-27 |
| AS-Q12 | Что делать с конфликтом, оставленным в индексе (после неудачного возврата stash) | Причина блокировки `unmerged`: кнопки недоступны, пока владелец не решит конфликт | 2026-11-27 |
