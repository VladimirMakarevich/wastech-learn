| AS-Q1 | Сообщение коммита: только автоматическое или редактируемое | Автоматическое по составу изменений, в поле, которое можно изменить перед синхронизацией (AS-F05, design D10) | 2026-11-27 |
| AS-Q2 | Напоминать ли о синхронизации | Мягко на итогах сессии, если оценки не отправлены; отправка только по нажатию (AS-F10) | 2026-11-27 |

| AS-Q4 | Когда оценки считаются «не отправленными» для AS-F10 | Когда в состоянии git есть незакоммиченные пути `reviews/` или `ahead > 0` | 2026-11-27 |
| AS-Q5 | Какая клавиша для архива на Review | `a`, без подтверждения, с «Вернуть» в тосте; `!` остаётся «отложить» (design D13) | 2026-11-27 |
| AS-Q7 | Что говорить, если в контент-репозитории не заданы `user.name` и `user.email` | Отдельный код `identity-missing`; приложение называет команду `git config user.name` и `user.email` (фаза 01) | 2026-11-27 |
| AS-Q8 | Где тексты ошибок `git-*` и `card-*`: в каталоге `core` (план фазы 01) или приложения (design D12) | Коды и схемы ответов — в `core/schema/app.ts`, общие для сервера и приложения; тексты — в каталоге приложения: их показывает только оно, и там же тесты паритета, литералов и тона (AC-F15). Каталог `core` остаётся за CLI и MCP | 2026-11-27 |
| AS-Q9 | Отдельный код `no-upstream` у синхронизации или причина блокировки | Причина `blocked.reason` (нет upstream, detached HEAD, идущая операция, нет git) в одной форме `blocked: { reason }` в `GET /api/git` и в ответе `POST` с кодом `blocked` | 2026-11-27 |
| AS-Q10 | Как отличить «нет сети» от «нужен пароль» | Отдельный код `offline` по фразам ssh и git о недоступном хосте; `auth-required` и таймаут считаются только у команд, которые ходят к удалённому | 2026-11-27 |
| AS-Q11 | Что откатывать, если сбой после pull | Сбой до конца pull возвращает коммит и индекс к состоянию до нажатия. После pull откат превратил бы полученные коммиты в правки рабочего дерева, поэтому сбой push и правки, оставшиеся в stash, сохраняют локальный коммит до следующей синхронизации; AC-N02b для них не действует | 2026-11-27 |
| AS-Q12 | Что делать с конфликтом, оставленным в индексе (после неудачного возврата stash) | Причина блокировки `unmerged`: кнопки недоступны, пока владелец не решит конфликт | 2026-11-27 |
| AS-Q13 | Нужен ли `requestId` маршрутам записи приложения (design D7) | Нет: приложение не повторяет запрос, как чат, а архив, возврат и статус темы идемпотентны по состоянию файла. Статус карточки идёт через тот же `updateCard`, что у MCP; ответы — `200 { status: "written" }`, `409` с находками или кодом | 2026-11-27 |
| AS-Q14 | Куда возвращается ссылка при отмене удаления | Строка из `index.md` последнего коммита встаёт после ближайшей карточки, которая стояла перед ней и есть в списке сейчас; остальные правки `index.md` не трогаются. Нет удаления после коммита — код `nothing-to-restore` | 2026-11-27 |
| AS-Q15 | Что показывает индикатор, когда всё закоммичено, но не отправлено | Срочное первым: оценки ещё не на диске → «N изменений не закоммичено» → «синхронизация недоступна» → «готово к отправке» с ↑N → «есть коммиты к получению» → «всё синхронизировано»; ↑ и ↓ — числами рядом, полные фразы — в `aria-label` | 2026-11-27 |
| AS-Q16 | Горячие клавиши экрана при открытом диалоге и на кнопке в фокусе | Пока открыт диалог, клавиши экрана и глобальные не работают; Enter на кнопке или ссылке нажимает её, а не клавишу экрана (раньше Home начинал сессию по Enter на любой кнопке); пробел остаётся за экраном, как на Review | 2026-11-27 |
| AS-Q6 | Как Home показывает архивные темы «по запросу» (AS-F13) | Кнопка «Показать N тем в архиве» под списком доменов раскрывает их отдельной группой; домен, где все темы в архиве, из списка уходит (фаза 06) | 2026-11-27 |
| AS-Q17 | Как Review убирает карточку по `a`, не дожидаясь записи и пересборки | Сессия откладывает карточку, как `b`, и идёт дальше; запись `retired` идёт следом, тост держится 8 с с кнопкой «Вернуть». Возврат делает карточку `active`, но в текущую сессию она не возвращается | 2026-11-27 |
| AS-Q18 | Где отменить удаление, если карточки уже нет в bundle | В Cards над таблицей — группа «Удалено после последнего коммита» из состояния git с кнопкой «Отменить удаление»; та же кнопка — в тосте после удаления | 2026-11-27 |
| AS-Q19 | Как вернуть архивную карточку с клавиатуры, если тост с «Вернуть» исчезает | Тост с действием держится 8 с и не исчезает, пока на нём указатель или фокус; с клавиатуры основной путь — Cards: фильтр «в архиве» и «Вернуть» в боковой панели. Статус `retired` везде называется «в архиве», как действие | 2026-11-27 |
| AS-Q20 | Уходит ли удалённая карточка с историей из статистики (AS-F12) | Из очереди и прогноза — да; её прошлые ответы остаются в true retention, потому что replay и метрики идут по всему журналу. Фильтр статистики по колоде — отдельная задача, если понадобится; диалог удаления говорит, как есть | 2026-11-27 |
