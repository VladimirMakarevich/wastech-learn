# Приложение: синхронизация с git и действия над карточками

- **Slug:** `app-sync-and-cards`
- **Статус:** in-progress
- **Создано:** 2026-11-27
- **Владелец:** Vladi Makarevich

## Кратко

Приложение показывает, что в контент-репозитории не закоммичено (индикатор, страница темы, Cards), синхронизирует его с удалённым одной кнопкой (commit только `content/`, `reviews/`, `inbox/`, pull с rebase, push) и позволяет архивировать, возвращать и удалять карточки и архивировать темы. Логика git и записи — в `content-fs` с теми же проверками, что у MCP; сервер тонкий; новую границу фиксирует ADR-0017. Всё локально ([ADR-0016](../../adr/0016-local-only.md)). Работа разбита на 7 фаз.

## Как ведётся спека

Спека собирается skill `spec-task`: по одному документу, сначала основа, план последним, каждый документ согласуется с владельцем. Согласованный `plan/index.md` передаётся в реализацию через skill `implement`.
