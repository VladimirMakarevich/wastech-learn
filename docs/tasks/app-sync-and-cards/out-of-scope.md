# Вне рамок - приложение: синхронизация с git и действия над карточками

[⌂ index](index.md)

## Не входит в задачу

- **Автоматика git.** Коммит после каждой оценки, push и pull по таймеру, при закрытии вкладки или при старте сервера. Всё - только по нажатию (AS-F10 лишь напоминает).
- **Разрешение конфликтов в приложении.** Нет просмотра diff, выбора «моё или их» и продолжения rebase: при конфликте операция откатывается, решение - в VS Code или терминале.
- **Работа с git сверх синхронизации.** Создание и переключение веток, выбор удалённого, force push, история коммитов, diff отдельного файла, `git init`, `clone`, настройка upstream, ввод паролей и токенов.
- **Выбор файлов для коммита.** Пути из `content/`, `reviews/` и `inbox/` коммитятся вместе, по одному не выбираются. «Другое» (`.codex/`, `.claude/`, `.agents/`, `skills-lock.json`, конфиги) из приложения не коммитится.
- **Команда `wastech-learn sync` и инструмент MCP для синхронизации.** Логика будет в `content-fs` и пригодится им позже, но сами команды - отдельная задача.
- **Редактирование и создание карточек в приложении.** Текст правится в VS Code (`e`), новые карточки - через захват в чате. Пометка «переписать» (`r`, FR-215) тоже не здесь.
- **Удаление тем и строк журнала.** Тему можно только архивировать (AS-F13). Журнал append-only, приложение его не правит.
- **Массовые действия.** Архив и удаление по одной карточке, без выбора нескольких.
- **Hook проверки для Codex.** Отдельная тема захвата, к приложению не относится.

## Отложено

- **Массовый архив** выбранных в Cards карточек - после обкатки M5, если одиночных действий окажется мало.
- **`wastech-learn sync` в CLI** - когда понадобится синхронизация без открытого приложения.

## Не цели

- Заменить git-клиент или VS Code. Приложение закрывает частый путь «отправить оценки и правки, забрать чужие», остальное - в привычных инструментах.
- Облако и мобильная версия ([ADR-0016](../../adr/0016-local-only.md)).
