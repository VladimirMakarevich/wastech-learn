Решения: `git status` с `GIT_OPTIONAL_LOCKS=0`, чтобы обновление индикатора не ломало коммит владельца на `index.lock`; файлы `content/` вне темы — `area: topic` без `topic` (их коммитит синхронизация); наблюдатель сообщает о любых файлах вне `.git/`, `.cache/`, `node_modules/` как `other`; сообщение коммита всегда называет устройство. Замер на копии golden — `benchmark.test.ts` сервера, бюджет 300 мс.
- 2026-11-27 — фаза 03: `syncRepository` и `pullRepository`, маршруты `POST /api/git/sync` и `/api/git/pull` через очередь `Workspace`; отказ — `409` с `{ code, … }`, кривое тело — `400 body-invalid` с полем. Решения: в коммит идут явные пути синхронизации с `--only`, поэтому застейдженное владельцем вручную в него не попадает; `--cleanup=whitespace`, чтобы строка с `#` не пропадала; любой сбой до push возвращает и коммит, и индекс к состоянию до нажатия (`reset --soft` и `read-tree`), отказ push оставляет коммит; push — явно в `branch.<имя>.merge` своего remote, не по `push.default`. AC-F08b проверен заглушкой ssh, которая отвечает отказом ключа, и `GIT_ASKPASS=false` — сеть не открывается; отдельно — таймаут, который останавливает всю группу процессов. После ревью: пути для `git add` фильтруются по рабочему дереву и индексу (удалённое через `git rm` не ломает синхронизацию), `GIT_LITERAL_PATHSPECS`, счёт полученных коммитов от `HEAD` до upstream, остановленный rebase узнаётся по папкам `rebase-*`; решены AS-Q10…AS-Q12.
