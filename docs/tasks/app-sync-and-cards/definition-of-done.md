# Definition of done — приложение: синхронизация с git и действия над карточками

[⌂ index](index.md) · критерии — [acceptance-criteria.md](acceptance-criteria.md)

## Базовые ворота проекта

Те же, что в [DoD вехи M2](../m2-core/definition-of-done.md): `npm run lint` и `npm test` зелёные, логика с тестами, комментарии объясняют «почему», точные версии, Conventional Commits без строк об агенте и только после «да» владельца, `/code-review` после каждой фазы. Для фаз, которые трогают `app` или `server`, ещё `npm run build` и `npm run test:e2e`. Действуют для каждой фазы плана.

## Ворота этой задачи

- [x] ADR-0017 «Сервер приложения пишет контент и запускает git» принят **до** первого маршрута записи; в том же изменении обновлены [.rules/security.md](../../../.rules/security.md) (локальный сервер: git без оболочки, только пути `content/`, `reviews/`, `inbox/`, сеть только по нажатию) и строка в «Последствиях» [ADR-0007](../../adr/0007-local-server-phase-1.md).
- [x] Новых зависимостей нет: git — внешняя программа владельца, вызывается через `node:child_process`.
- [x] Все автоматические критерии из [acceptance-criteria.md](acceptance-criteria.md) проходят; тесты git идут на временных репозиториях с bare-удалённым и не открывают сеть.
- [x] Замер AC-N03: `GET /api/git` на реальном `wastech-learn-content` записан в журнал изменений спеки.
- [ ] Видимость смены статуса < 2 с на реальном контенте — на ручной приёмке (на копии golden покрыта e2e).
- [ ] Ручная приёмка на реальном контенте записана в журнал изменений спеки: синхронизация оценок с `desk1`, получение на втором компьютере, архив и возврат карточки; `check` — 0 ошибок.
- [x] Новые экраны и диалоги прошли ревью по DESIGN.md (skill `impeccable`) в обеих темах; замечания исправлены или записаны в [questions.md](questions.md).
