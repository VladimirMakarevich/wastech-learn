# M4 — приложение: повторение, чтение и статистика в браузере

- **Slug:** `m4-app`
- **Статус:** in-progress
- **Создано:** 2026-11-26
- **Владелец:** Vladi Makarevich

## Кратко

Третья кодовая веха: десктопное приложение на Angular + CDK в стиле Evening Glass и локальный сервер `wastech-learn serve`, через который оно читает content bundle и дописывает журнал. Логика оценки уходит в новый чистый пакет `session` (ADR-0015), общий для квиза MCP и приложения; replay, очередь и метрики считаются в браузере. Экраны Home, Review, Session end, Topic, Browser, Stats и Settings на ru/en/pl, озвучка польского. Готово, когда сессия из 20 review items проходится только с клавиатуры. Работа разбита на 14 фаз.

## Как ведётся спека

Спека собирается skill `spec-task`: по одному документу, сначала основа, план последним, каждый документ согласуется с владельцем. Согласованный `plan/index.md` передаётся в реализацию через skill `implement`.
