# Проблема - M4, приложение

[⌂ index](index.md)

## Проблема, как она поставлена

Контент и журнал есть, но повторять по-настоящему негде. Главный ритуал системы - вечерняя сессия на десктопе: вопрос, попытка, ответ со схемой, оценка ([journeys](../../product/journeys.md): J-03). Веха M4 из [roadmap](../../roadmap.md) - приложение на Angular + CDK в стиле Evening Glass с экранами Home, Review, Session end, Topic, Browser, Stats (минимум) и Settings, интерфейсом на ru/en/pl, озвучкой польского и локальным сервером. Готово, когда сессия из 20 review items проходится только с клавиатуры.

## У кого эта проблема

- **Автор** - единственный пользователь. Повторяет вечером в браузере на десктопе, нерегулярно; читает темы перед повторением и после ошибок; учит польский; правит карточки в VS Code (J-03, J-04, J-05, J-07, J-08).
- **Будущая мобильная сборка** (фаза 2) как второй потребитель того же UI: всё, что UI знает о журнале, должно идти через `ReviewStore`, иначе Capacitor потребует переписывания.

## Текущая ситуация

- Повторять можно только в чате через `learn-quiz`: батчи до 10 карточек, без выбора уверенности кнопками, без отрисованных схем и кода, с расходом лимита подписки (R-04).
- `wastech-learn build` собирает content bundle, но его никто не показывает. Поискового индекса в bundle ещё нет.
- [Прототип](../../../prototypes/desktop-ui/README.md) показывает все экраны в Evening Glass, но FSRS там не считается: интервалы, R и статистика демонстрационные, оценки не пишутся в журнал.
- Локального сервера нет: пакета `server` и команды `serve` не существует, контракт `ReviewStore` есть только в [components](../../architecture/components.md).
- Метрик для Stats (true retention, прогноз нагрузки) в `srs` нет; кэша replay в `node:sqlite` тоже нет.
- В репозитории нет Angular, не выбран инструмент UI-тестов (ADR-0006 оставил это на M4).

## Почему сейчас

- Следующая веха после M3. Обкатке M5 нужны 4 недели реального использования по ≥3 сессии в неделю и ≥300 повторений - без приложения их не набрать.
- Ядро готово: схемы, bundle, replay, очередь, бэклог, симуляция (M2) и запись контента из чата (M3).
- Чем раньше копится реальный журнал из основного интерфейса, тем раньше можно править лимиты и порядок очереди по данным.

## Сигналы и факты

- Критерии MVP из требований: следующая карточка появляется меньше чем за 50 мс (NFR-05); правка карточки в VS Code видна в приложении меньше чем через 2 с; после 14 дней без сессий главная показывает план возврата, а не число пропущенных дней; статистика совпадает с ручным подсчётом на golden-журнале; переключение языка меняет все подписи ([fr-review](../../requirements/fr-review.md), [fr-content](../../requirements/fr-content.md), [fr-insights](../../requirements/fr-insights.md), [fr-language](../../requirements/fr-language.md)).
- Риски из [risks-and-questions](../../risks-and-questions.md): нерегулярный ритм превращается в отказ (R-10); перенос Evening Glass в Angular займёт больше, чем ожидается (R-11).
- Вопросы проекта, отложенные до M4: тёмная тема SVG-диаграмм (Q-10), запуск сервера без ручной команды (Q-11), стемминг ru и pl в поиске (Q-12).
- Ревью прототипа закрыло все 13 дизайн-вопросов ([open-decisions](../../../prototypes/desktop-ui/open-decisions.md)); токены и компоненты описаны в [DESIGN.md](../../../DESIGN.md).

## Ограничения, заданные заранее

- Desktop-first Angular: standalone-компоненты, signals, без zone.js; CDK только для поведения, без Angular Material; i18n переносится из `wastechlab-mobile-template` как донор частей ([ADR-0006](../../adr/0006-headless-core-angular-ui.md)).
- Вид - Evening Glass, источник правды - DESIGN.md; стили и токены переносятся из прототипа.
- `app` импортирует только `core` и `srs`; контент - только из bundle, состояние - только через `ReviewStore`; FSRS и очередь считаются в клиенте ([.rules/architecture.md](../../../.rules/architecture.md)).
- Локальный сервер на Hono слушает только `127.0.0.1`, валидирует каждое событие схемой `core` и дописывает в `reviews/<device>/web-YYYY-MM.jsonl` ([ADR-0007](../../adr/0007-local-server-phase-1.md)).
- Без API-ключей, вызовов моделей, телеметрии и CDN; шрифт Inter лежит локально ([.rules/security.md](../../../.rules/security.md)).
- Тексты без вины и стриков, на трёх языках ([interaction](../../ux/interaction.md)); всё повторение - с клавиатуры, контраст WCAG AA (NFR-11).
