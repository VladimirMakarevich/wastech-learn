# Вне рамок — M4, приложение

## Не входит в задачу

- **Мобильная сборка** — Capacitor, SQLite outbox, sheet инспектора, закреплённая панель решения, жесты и таб-бар телефона — фаза 2 ([ADR-0006](../../adr/0006-headless-core-angular-ui.md)). Smoke-сборка под Capacitor из проверки NFR-15 — тоже фаза 2; в M4 только адаптивная раскладка без горизонтальной прокрутки.
- **Облако** — Worker, D1, Access, облачный `ReviewStore`, remote MCP — фаза 2 ([ADR-0013](../../adr/0013-cloud-sync-phase-2.md)).
- **Режимы Later**: cram (FR-212), смешанная сессия (FR-213), подсказка о смысле Hard (FR-216), лестница подсказок для `scenario` (FR-217).
- **Аналитика Later**: калибровка (FR-404), fix list (FR-405), журнал рефлексии (FR-406), Bloom-баланс (FR-407), оптимизатор весов (FR-408), heatmap (FR-411), mastery (FR-412), UI leech rate. Leech в M4 — фильтр в Browser.
- **Навигация Later**: язык запросов как в Anki (FR-306), карта знаний (FR-308), связанные темы на странице темы и в итогах (FR-313), экспорт в Anki и CSV (FR-314).
- **Язык Later**: офлайн-аудио Piper (FR-506), переводы summary и карточек (FR-507), type-in answer (FR-508).
- **Напоминания** (FR-410) — пушей нет; счётчик на главной показывается, только когда пользователь сам открыл приложение.
- **Кнопка «Отложить для ИИ-проверки»** и тег `ai-check` ([tutor-and-grading](../../ai/tutor-and-grading.md)) — Later.
- **Приёмка M3 на реальных темах** (фаза 11 спеки [m3-capture](../m3-capture/index.md)) и публикация пакетов в npm — отдельные шаги вне M4.

## Отложено

- **Правка DR и лимитов из Settings** — Later; в M4 только показ (M4-Q1).
- **Пометка «переписать» (`r`)** — вместе с fix list; `b` в M4 действует до конца сессии и не пишется в журнал (M4-Q2).
- **Retire из повторения** — Later; в M4 карточку выводят через VS Code или `update_card` в чате (M4-Q3).
- **Метрика «доля переписанных карточек»** (R-09) — считается при обкатке M5 по журналу и git-истории, экрана в M4 нет.

## Сознательно не делаем

- **Приложение не пишет контент.** Markdown, SVG и `learn.config.json` меняются только в VS Code или через MCP в чате; приложение дописывает только журнал.
- **В вебе нет ИИ.** Никаких вызовов моделей и ИИ-оценки ответов: открытые карточки оцениваются по рубрике-чеклисту самим пользователем ([ADR-0008](../../adr/0008-capture-via-subscription-chats.md)).
- **Без стриков, серий и счётчика пропущенных дней** — ни на одном экране ([interaction](../../ux/interaction.md)).
- **Без Angular Material и Ionic.** Из `wastechlab-mobile-template` переносится только i18n; Firebase, auth, OpenAPI-клиент, NgModules и zone.js не переносятся.
- **Без доступа по сети.** Сервер слушает только `127.0.0.1`: открыть приложение с телефона по локальной сети нельзя, аутентификации нет.
- **Без PWA и service worker.** Офлайн обеспечивает локальный сервер.
- **Один сервер — один контент-репозиторий**, без переключения на лету.
- **Прототип не переписывается и не развивается.** [prototypes/desktop-ui](../../../prototypes/desktop-ui/README.md) остаётся справочником компоновки; источник правды по виду — DESIGN.md.
