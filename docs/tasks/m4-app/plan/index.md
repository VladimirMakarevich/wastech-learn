# План реализации — M4, приложение

[⌂ спека](../index.md) · строит [design.md](../design.md) к [acceptance-criteria.md](../acceptance-criteria.md)

## Стратегия

Сначала решение о границе: ADR-0015 и пакет `session` (01), потом чистая логика, на которой стоит UI: метрики (02), движок сессии (03), индекс поиска в bundle (04), наблюдение за файлами (05). Затем сервер (06) — с ним у приложения есть данные. Приложение строится от каркаса и e2e-обвязки (07) через слой данных и основу UI (08) к экранам: сначала Review как главный сценарий (09), потом Home и итоги (10), Topic и Browser (11), Stats и Settings (12). Проход по качеству (13) и приёмка с документами (14) — последними. Критический путь — 01 → 03 → 09: движок сессии решает, проходит ли главный критерий вехи.

## Общее для всех фаз

- **Коммиты:** Conventional Commits (`feat(session): …`, `feat(server): …`, `feat(app): …`), только после «да» владельца, без строк об агенте.
- **Тесты:** временные копии golden, никогда не настоящий контент; время и сид заданы явно; e2e — с `page.clock`.
- **Документы:** фаза, которая меняет поведение или границу, обновляет [components](../../../architecture/components.md) и правила в том же коммите; фаза 14 сводит остальное.
- **Зависимости:** точные версии; лицензия и то, что тянет пакет, записываются в журнал изменений спеки в фазе, где он появляется.
- **DoD:** [definition-of-done.md](../definition-of-done.md).

## Передача в реализацию

Фазы выполняет skill `implement` по одной: `assess-refactor` перед кодом, статус в этой таблице, `/code-review` через subagents после фазы.

## Риски

| Риск | Вероятность | Митигация |
| --- | --- | --- |
| Перенос Evening Glass в Angular дороже ожидаемого (R-11) | средняя | Токены и CSS берутся из прототипа как есть; только MVP-экраны; одно ревью дизайна в фазе 13 |
| Replay 50k событий в браузере дольше 5 с | низкая | Замер в фазе 03 на синтетическом журнале; запасной путь — Web Worker, Node API не нужны |
| Полная пересборка bundle реального репозитория дольше 1.5 с (Shiki) | средняя | Замер в фазах 06 и 13; инкрементальная сборка по файлам (design D5) |
| `fs.watch` пропускает события (лимиты inotify, сетевые папки) | низкая | Задержка и полная пересборка; кнопка «Обновить» в оболочке (FR-311) |
| Нестабильные e2e | средняя | Фиксированное время, только Chromium, копия golden на каждый прогон, без ожиданий по таймеру |
| Angular без zone.js и без TestBed усложняет тесты компонентов | низкая | Логика в чистых модулях под Vitest, компоненты проверяет e2e |
