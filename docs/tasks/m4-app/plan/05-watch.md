# Фаза 05 — Наблюдение за файлами

[⌂ plan](index.md) · [спека](../index.md)

- **Статус:** ☐
- **Зависит от:** —
- **Даёт:** `watchRepository` в `content-fs`

## Цель

Сообщать о правках контента, конфига и чужих журналов, но не о собственной дозаписи сервера (design D4).

## Шаги

1. `content-fs/watch.ts`: `fs.watch` с `recursive`, задержка 200 мс, классы изменений `content`, `reviews`, `config`; `.git/` и `.cache/` игнорируются.
2. Регистрация своей дозаписи: путь и размер файла после записи; совпадающее изменение не объявляется.
3. Остановка наблюдения без висящих дескрипторов.

## Затронутые файлы

- `packages/content-fs/src/watch.ts`
- `packages/content-fs/src/index.ts`
- `packages/content-fs/test/watch.test.ts`

## Правила

IO только в `content-fs`; без новой зависимости вместо `fs.watch` ([coding-style](../../../../.rules/coding-style.md)).

## Тесты

Временная папка: правка карточки → `content`; строка в файле другого устройства → `reviews`; своя дозапись → тишина; серия правок → одно уведомление.
