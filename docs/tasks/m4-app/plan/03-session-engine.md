# Фаза 03 — Движок и итоги сессии

[⌂ plan](index.md) · [спека](../index.md)

- **Статус:** ☐
- **Зависит от:** 01, 02
- **Даёт:** Режимы, очередь в ходе сессии, отмена, bury, suspend, reset, рубрика, итоги

## Цель

Вся логика сессии — чистыми функциями над `(state, now)`, чтобы экран Review был тонким (design, «Движок сессии»).

## Шаги

1. `engine.ts`: `start(mode)` — «5 минут» по оценке времени без новых, «Вся очередь»; текущая карточка; `rate` → события и инкрементальный replay через `createReplayer`, пересчёт очереди (learning steps возвращаются в сессию).
2. `undo` — `undo` на последнюю группу событий, включая автоматический `suspend`; `bury` — скрытие до конца сессии без события (M4-Q2); `suspend`, `unsuspend`, `reset`.
3. `refresh(bundle, replayState)` — внешнее изменение без потери текущей карточки; исчезнувшая или не `active` карточка пропускается.
4. `rubric.ts` — оценка по отмеченным пунктам по правилам [tutor-and-grading](../../../ai/tutor-and-grading.md).
5. `summary.ts` — число, минуты, true retention сессии, ошибки при уверенности 3, прогноз на завтра.

## Правила

Детерминизм: время и RNG — входы; один и тот же журнал даёт то же состояние ([architecture](../../../../.rules/architecture.md)).
