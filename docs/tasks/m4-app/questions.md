| # | Вопрос | Ответ | Когда |

| M4-Q1 | Меняет ли Settings DR и лимиты доменов | Нет: в M4 Settings только показывает DR, лимиты и устройство, правка - в `learn.config.json` через VS Code; запись из приложения - Later | 2026-11-26 |
| M4-Q2 | Как хранить `b` и `r` без подходящих `kind` в событии v1 | `b` скрывает карточку до конца сессии, в журнал ничего не пишется; `r` откладывается до fix list (Later) | 2026-11-26 |
| M4-Q3 | Retire из повторения меняет front matter | В M4 только `suspend` и `unsuspend`; retire - через VS Code или `update_card` в чате | 2026-11-26 |
| M4-Q4 | Нужен ли кэш replay в `node:sqlite` | Нет: replay в клиенте, бенчмарк NFR-05 проходит без кэша (design D6) | 2026-11-26 |
| M4-Q5 | Инструмент UI-тестов | Vitest для чистых модулей `app`, Playwright (Chromium) с `@axe-core/playwright` для сценариев (design D14) | 2026-11-26 |
| M4-Q6 | Тёмная тема SVG-диаграмм (Q-10) | `core.prepareSvg` убирает `<style>` и белый фон, цвета задают токены Evening Glass; второго рендера нет (design D10) | 2026-11-26 |
| M4-Q7 | Запуск сервера без ручной команды (Q-11) | Later; в M4 `serve` сам открывает браузер (`--no-open` отключает) | 2026-11-26 |
| M4-Q8 | Стемминг ru и pl (Q-12) | Без стемминга, как в M3: нижний регистр и снятие диакритики (design D13) | 2026-11-26 |
| M4-Q9 | Новый пакет `session` | Да: чистый пакет на `core` и `srs`, ADR-0015 - до кода (design D1) | 2026-11-26 |
