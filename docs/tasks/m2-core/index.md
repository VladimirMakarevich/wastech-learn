## Кратко

Первая кодовая веха: headless-пакеты `core`, `srs`, `content-fs` и CLI `check`, `build`, `render`, `simulate`. Они проверяют контент вторым уровнем после mdlint, собирают content bundle, считают расписание из append-only журнала через ts-fsrs 6 (FSRS-7) и строят очередь дня с политикой бэклога. Без них не начать ни захват через MCP (M3), ни приложение (M4). Работа разбита на 11 фаз, каждая оставляет lint и тесты зелёными.

## Как ведётся спека

Спека собирается skill `spec-task`: по одному документу, сначала основа, план последним, каждый документ согласуется с владельцем. Согласованный `plan/index.md` передаётся в реализацию через skill `implement`.
