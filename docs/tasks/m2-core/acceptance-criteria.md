# Критерии приёмки — M2, ядро

[⌂ index](index.md) · требования — [requirements.md](requirements.md) · дизайн — [design.md](design.md)

Каждый критерий проверяется автоматическим тестом, если в колонке «Проверка» не сказано иное. «Golden» — копия golden sample в `fixtures/golden/`.

## Функции

| # | Дано → когда → тогда | Проверка |
| --- | --- | --- |
| AC-F01a | Golden-конфиг без `learn.local.json` → загрузка → `device` равен hostname, остальные поля разобраны | unit `content-fs` |
| AC-F01b | В `learn.config.json` `desiredRetention: 1.5` → загрузка → ошибка с файлом и полем `srs.desiredRetention`, код CLI `2` | unit + CLI |
| AC-F02a | Golden → разбор → 3 темы, 30 карточек, у `cloze` варианты `c1`…`cN`, у `vocab` — `fwd` и `rev`, у остальных — `main` | golden |
| AC-F02b | Карточка без `status` → разбор → находка-ошибка с файлом и полем | unit |
| AC-F02c | Правка вне Question и Answer → `contentHash` не меняется; правка в Answer → меняется | unit |
| AC-F03a | Golden → `check` → 0 ошибок, код `0` | golden + CLI |
| AC-F03b | Для каждого правила из таблицы mdlint-policy есть фикстура-нарушение → `check` → находка этого правила, код `1` | unit по правилу |
| AC-F03c | Из копии пресета удалено правило `SIZE-001` → `check` → предупреждение о расхождении, код `0`; добавлено своё правило → находок нет | unit |
| AC-F03d | `--lang pl` → тексты находок на польском; в каталогах ru, en, pl одинаковые ключи | unit + тест паритета |
| AC-F04a | Golden → `build` с фиксированным `builtAt` → bundle совпадает со снимком; повторный запуск даёт тот же файл байт в байт | golden-снимок |
| AC-F04b | В summary есть `<script>` и `onclick` → `build` → в HTML их нет, SVG, KaTeX и классы Shiki на месте | unit |
| AC-F04c | Ошибка схемы в одной карточке → `build` → bundle не записан, код `1`, файл назван | CLI |
| AC-F05 | Изменён `.mmd` → `render --check` → файл назван устаревшим, код `1`; после `render` → маркер совпадает с хэшем, `--check` даёт `0` | CLI на временной копии; Chromium нужен |
| AC-F06a | Два файла журнала с общим событием и строкой-мусором → чтение → дубль отброшен, мусор — находка с файлом и номером строки, порядок по `ts`, затем `id` | unit |
| AC-F06b | `undo` на событие `review` → чтение → отменённое событие не участвует в replay | unit |
| AC-F06c | Дважды дописать одно и то же событие → в файле одна строка | unit, временная папка |
| AC-F07a | Карточка: Good, Good, Again → replay → `lapses = 1`, фаза relearning, `due` по шагу `10m` или по модели, если она дольше | unit против прямого вызова ts-fsrs |
| AC-F07b | `lapses` достигли `leechThreshold` → replay → признак leech | unit |
| AC-F07c | `reset`, `suspend`, `manual_due`, `practice` → replay → поведение по таблице в design | unit на каждый вид |
| AC-F08a | Есть learning с подошедшим шагом, due и новые → очередь → порядок: learning, due вперемешку по доменам, новые в лимите домена | unit |
| AC-F08b | Два варианта одной карточки и две карточки одной `idea` due сегодня → очередь → в день попадает по одному | unit + property |
| AC-F08c | Бэклог больше `2 × reviewsPerDay` → очередь → новых 0; бэклог меньше `reviewsPerDay` → первые 3 дня половина лимита новых | unit |
| AC-F08d | Режим «5 минут» → очередь → сумма оценок не превышает 5 минут, кроме дорешиваемой карточки, новых нет | unit |
| AC-F09 | `simulate` с перерывом 14 дней, сессии по 15 минут, тем же сидом → отчёт одинаковый при повторе; бэклог разобран за ≤5 дней; три порядка сравнены в отчёте | unit + CLI |

## Качества

| # | Дано → когда → тогда | Проверка |
| --- | --- | --- |
| AC-N01 | Журнал около 1000 событий → replay трижды: как есть, с перемешанными строками, с перемешанными файлами → три снимка побайтно равны; `TZ` процесса не влияет | тест детерминизма |
| AC-N02 | 5k карточек, 50k событий → replay < 5 с; выбор следующей карточки < 50 мс; `build` golden < 10 с | бенчмарк-тест |
| AC-N03 | Любой журнал из генератора fast-check → очередь → лимиты соблюдены, siblings не в один день, learning первыми, `undo` возвращает прежний снимок | property |
| AC-N04 | `core` или `srs` импортирует `node:*` или друг друга → `npm run lint` падает | lint |
| AC-N05 | Событие `v: 1` с незнакомым необязательным полем → читается; событие `v: 2` → находка, не падение | unit |
| AC-N06 | Вывод `check` на фикстурах-нарушениях не содержит текста вопросов и ответов; в коде нет сетевых вызовов | unit + ревью |
