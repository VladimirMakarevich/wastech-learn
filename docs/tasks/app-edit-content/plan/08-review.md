# Фаза 08 — Правка на Review

[⌂ plan](index.md) · [спека](../index.md)

- **Статус:** ☑
- **Зависит от:** 05
- **Даёт:** Редактор после показа ответа, сессия продолжается

## Цель

Поправить карточку в момент, когда ошибка замечена, и оценить уже исправленный текст (AE-F04).

## Шаги

1. `packages/app/src/app/screens/review/review.ts` и `review.html`: `e` после показа ответа открывает редактор вместо карточки; до показа ответа `e` ничего не делает. Клавиши оценки в поле не срабатывают (уже `isEditable`).
2. После сохранения или отмены карточка снова на экране с ответом: сессия обновляется от нового bundle своим правилом, оценка берёт новый `contentHash`. После «новой карточки» сессия по своему правилу переходит к следующей.
3. Ссылка VS Code — по `Shift+E`; подсказки клавиш обновлены; маршрут Review получает `canDeactivate`.
4. `packages/app/e2e/`: правка ответа и оценка `3` с новым `contentHash` в журнале; `e` до показа ответа.

## Затронутые файлы

- `packages/app/src/app/screens/review/`
- `packages/app/src/app/app.routes.ts`
- `packages/app/e2e/` (сценарии правки на Review)

## Правила

Логика сессии остаётся в `session` и `review-session.ts`; журнал пишется только событиями сессии ([architecture](../../../../.rules/architecture.md)).
