# Фаза 07 — Правка на Topic

[⌂ plan](index.md) · [спека](../index.md)

- **Статус:** ☐
- **Зависит от:** 05
- **Даёт:** Редактор файлов темы с вкладками и секцией с экрана

## Цель

Правка summary, паспорта и материалов там, где тема читается, с курсором на секции, которую читал (AE-F02, AE-F03).

## Шаги

1. `packages/app/src/app/screens/topic/topic.html` и `topic.ts`: карандаш в шапке и `e`; редактор вместо оглавления, статьи и колонки; вкладки Summary, Паспорт, Материалы; карандаш у блока «Материалы» сразу открывает `materials.md`.
2. Переключение вкладки с изменённым текстом — подтверждение из фазы 05.
3. Секция с экрана: верхняя видимая секция статьи передаётся редактору как `section`, курсор встаёт на строку `## <Name>`.
4. Ссылка VS Code в шапке — по `Shift+E`; маршрут Topic получает `canDeactivate`.
5. `packages/app/e2e/`: summary с секции «Trade-offs», вкладки и материалы, сохранение и новый текст на странице.

## Затронутые файлы

- `packages/app/src/app/screens/topic/`
- `packages/app/src/app/app.routes.ts`
- `packages/app/e2e/` (сценарии правки на Topic)

## Правила

Как в фазе 06; тексты вкладок — на языке интерфейса, текст темы — с её `lang`.

## Тесты

Playwright на golden-копии: сценарии шага 5.
