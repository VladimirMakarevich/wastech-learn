# Вне задачи — приложение: правка тем и карточек в браузере

[⌂ index](index.md) · ограничивает [requirements.md](requirements.md)

## Не входит в задачу

- **Коммит, push, pull и индикатор незакоммиченных изменений** — в [app-sync-and-cards](../app-sync-and-cards/index.md) (AS-F01…AS-F10). Эта задача только записывает файлы.
- **Кнопки «В архив», «Удалить» и архив темы** — там же (AS-F11…AS-F13). Поменять `status` текстом во front matter редактор не мешает: это обычная правка с проверкой.
- **Диаграммы (`.mmd` и `.svg`).** После правки источника SVG нужно перерендерить, иначе `check` поймает устаревший рендер ([ADR-0010](../../adr/0010-diagrams-as-code.md)). Рендер остаётся за `wastech-learn render` и skills.
- **Новые темы и карточки с нуля, перенос карточки в другую тему, переименование темы.** Захват идёт через чаты ([ADR-0008](../../adr/0008-capture-via-subscription-chats.md)); новая карточка появляется только как преемник при смене смысла (AE-F11).
- **Файлы вне тем:** `learn.config.json`, `inbox/`, `journal/`, `AGENTS.md`, skills, конфиги. Settings их только показывает ([screens](../../ux/screens.md)).
- **Журнал повторений.** Он append-only ([review-log](../../content/review-log.md)); ни одна правка его не меняет.

## Отложено

- **Живое превью Markdown во время правки** — после записи экран и так перерисуется за 2 с. Вернуться, если правка вслепую окажется частым источником ошибок.
- **Подсветка синтаксиса и номера строк** (CodeMirror и подобные) — это новая зависимость в приложении. Вернуться после M5, если простого текстового поля не хватит.
- **Правка одной секции summary вместо всего файла** — AE-F03 уже открывает редактор на нужной секции.
- **Черновик, который переживает перезагрузку страницы** — пока хватает подтверждения перед потерей текста (AE-F07).
- **Слияние своей правки с чужой при конфликте** — AE-F14 только отказывает и сохраняет черновик. Вернуться, если конфликты станут обычным делом.
- **Отмена уже сохранённой правки из приложения** — откат идёт через git или VS Code; после [app-sync-and-cards](../app-sync-and-cards/index.md) изменения хотя бы видны в приложении.
- **Правка из Home, Stats, Session end и результатов поиска** — точки входа только Cards, Topic и Review.
- **Пометка «переписать» (`r`) и fix list** — FR-215 и FR-405, Later.

## Сознательно не делаем

- **Форму полей** для front matter и секций — владелец просил обычный Markdown-текст.
- **WYSIWYG-редактор** — файл остаётся тем же текстом, что в VS Code и в git.
- **Общий редактор файлов репозитория** — только файлы тем и карточек, которые есть в bundle.
- **Совместную правку** — пользователь один, всё работает только на его компьютере ([ADR-0016](../../adr/0016-local-only.md)).
- **Помощь ИИ в правке** — в продукте нет ключей и вызовов моделей ([.rules/security.md](../../../.rules/security.md)); переписать карточку с ИИ можно в чате через `update_card`.
