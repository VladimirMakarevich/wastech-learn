# Критерии приёмки — приложение: правка тем и карточек в браузере

[⌂ index](index.md) · требования — [requirements.md](requirements.md) · дизайн — [design.md](design.md)

«Копия» — временная копия golden sample (`fixtures/golden`). «Unit» — Vitest без диска; «на копии» — Vitest над копией через `content-fs`; «контракт» — маршрут через `app.request()` без сокетов; «e2e» — Playwright (Chromium) на `wastech-learn serve` над копией.

## Функции

| # | Дано → когда → тогда | Проверка |
| --- | --- | --- |
| AC-F01 | Cards, открыта карточка backpressure → кнопка «Править» или `e` → в панели текст файла, совпадающий с файлом на диске, фокус в поле | e2e |
| AC-F02 | Topic backpressure → карандаш в шапке → открыт `summary.md`; вкладки «Паспорт» и «Материалы» показывают `index.md` и `materials.md`; карандаш у «Материалов» сразу открывает `materials.md` | e2e |
| AC-F03 | Topic прокручен до «Trade-offs» → карандаш → курсор на строке `## Trade-offs`, строка видна в поле | e2e |
| AC-F04a | Review, ответ показан → `e`, правка `Answer`, `Ctrl+S` → карточка снова с ответом и новым текстом; оценка `3` пишет `review` с новым `contentHash` | e2e |
| AC-F04b | Review, ответ не показан → `e` редактор не открывает | e2e |
| AC-F05 | `Shift+E` на Cards, Topic и Review даёт ссылку `vscode://file/<абсолютный путь>` того же файла | e2e |
| AC-F06 | В редакторе `Ctrl+S` сохраняет, `Esc` без изменений закрывает без записи и без вопроса | e2e |
| AC-F07 | Текст изменён → `Esc`, переход на Home, `beforeunload` → каждый раз подтверждение; «Остаться» сохраняет текст | e2e |
| AC-F08a | Удалить строку `## Answer` → `Ctrl+S` → 422 `blocked`, файл на диске байт в байт прежний; находка `check` со строкой на языке интерфейса; выбор находки ставит курсор на эту строку | на копии + e2e |
| AC-F08b | Правка, ломающая якорь, на который ссылается другой файл → `blocked` с находкой в том файле, показанной как `путь:строка` | на копии |
| AC-F09 | Правка с одним предупреждением → `written`, предупреждение в ответе и на экране | на копии + e2e |
| AC-F10 | Изменён `id` во front matter → `blocked`, находка `card-id-changed` на строке `id:`, файл прежний | на копии |
| AC-F11a | Active-карточка: `Answer` переписан больше чем на 40% слов относительно открытого текста → 409 `decision-needed`; та же правка у `draft` или `retired` → `written` без вопроса | unit `cardEditDecision` + на копии |
| AC-F11b | Cloze-карточка: удалён пропуск `c2` → `decision-needed` с `removedVariants: ["c2"]`; добавлен `c3` → без вопроса. `basic` → `reversed` → `decision-needed` с `main` | unit |
| AC-F11c | `meaning: "same"` → тот же файл, `id` прежний, `active-edit` этого файла нет в находках. `meaning: "new"` → старый файл = текст с диска + `status: retired`; новый файл с новым `id`, `created` сегодня, `status: active`, `origin` старой; строка в `## Cards`; всё одной транзакцией | на копии |
| AC-F12 | Изменён `#` карточки → в `## Cards` темы новый заголовок, `index.md` и карточка записаны вместе | на копии |
| AC-F13 | `summary.md` с неизменённым `updated` → `updated` = сегодня в зоне конфига (время из теста); `updated`, изменённый пользователем, остаётся | на копии |
| AC-F14 | Редактор открыт, файл изменён на диске → `Ctrl+S` → 409 `content-changed`, файл с чужой правкой не тронут, текст в редакторе тот же; «Загрузить свежую версию» после подтверждения показывает файл с диска | на копии + e2e |
| AC-F15a | `written` → редактор закрыт, экран показывает новый текст без перезагрузки страницы, «Сохранено» видно; ответ приходит после пересборки bundle | контракт + e2e |
| AC-F15b | Тот же `PUT` повторён → `unchanged`, файл не переписан (время изменения прежнее) | на копии |
| AC-F16 | Новые ключи есть в ru, en и pl (паритет); аудит литералов чистый; ни одного текста с упрёком | unit `i18n` + ревью текстов |

## Качества

| # | Дано → когда → тогда | Проверка |
| --- | --- | --- |
| AC-N01a | `GET` и `PUT` для `learn.config.json`, `reviews/…`, `content/../x`, пути вне bundle и символической ссылки наружу → 404 `source-not-found`, на диске ничего не изменилось | контракт + на копии |
| AC-N01b | `PUT` с чужим `Origin` → 403, `text/plain` → 415, телом > 256 KB → 413, телом не по схеме → 400 | контракт |
| AC-N01c | Сбой записи → 500 с кодом (`io-failed`) без текста файла; сервер не выводит текст правки ни в ответы, ни в консоль | контракт с подменой `TransactionFs` + ревью диффа |
| AC-N02a | Сбой на третьем шаге транзакции «новой карточки» → обе карточки и `index.md` как до записи | на копии с подменой `TransactionFs` |
| AC-N02b | Два `PUT` одновременно к разным карточкам одной темы, оба меняют `#` → обе строки в `## Cards`, ни одна не потеряна | контракт |
| AC-N02c | После любой правки файлы `reviews/**` байт в байт прежние | на копии |
| AC-N03 | На реальном контент-репозитории: `GET` < 300 мс; `PUT` с проверкой, записью и пересборкой < 2 с (медиана 5 замеров, записана в журнал реализации) | ручной замер владельца |
| AC-N04 | Правка карточки, ошибка, исправление и сохранение — только с клавиатуры; фокус после закрытия на кнопке-источнике; диалоги держат фокус; axe без `serious` и `critical` в светлой и тёмной теме; ширина 360 px без горизонтальной прокрутки | e2e |
| AC-N05 | Сценарии e2e не делают сетевых запросов, кроме `127.0.0.1` | e2e (аудит сети) |
| AC-N06 | `npm run build` без превышения бюджета `initial` в `angular.json`; в `packages/app/package.json` нет новых зависимостей | сборка + ревью диффа |
