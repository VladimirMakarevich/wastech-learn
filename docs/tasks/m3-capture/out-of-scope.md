# Вне рамок - M3, захват

[⌂ index](index.md)

## Не входит в задачу

- **Remote MCP, OAuth, Cloudflare Worker** (FR-112) - фаза 2 ([ADR-0013](../../adr/0013-cloud-sync-phase-2.md)). В M3 только stdio для Claude Code.
- **MCP Apps** - карточка с кнопками в чате (FR-113), Later.
- **D2 и Excalidraw** (FR-114) - Later; `save_diagram` принимает только Mermaid.
- **Приложение, локальный сервер, `ReviewStore`** - M4.
- **Подключение к Claude Desktop (чат)** - Later; конфигурация та же, но проверяется только Claude Code.
- **Инструменты `suspend` и `unsuspend`**, ресурсы и промпты MCP - Later по [mcp-tools](../../ai/mcp-tools.md). Автоматический `suspend` для leech в `record_review` - входит.
- **Skills `learn-fix` и `learn-journal`** - Later.
- **Грейдеры `claude-cli` и `api`** - Later, вопрос условий подписки [Q-09](../../risks-and-questions.md). В M3 оценивает только сам ИИ в чате и подтверждает пользователь.

## Отложено

- **Тег `ai-check` из веба** - появится с приложением (M4 и Later).
- **Стемминг ru и pl в поиске** - [Q-12](../../risks-and-questions.md); в M3 нижний регистр и снятие диакритики, как в ADR-0014.
- **Публикация пакетов в npm** - отдельный шаг после M2 с согласия владельца; M3 ждёт его перед подключением контента (M3-F12).
- **Метрика «доля переписанных карточек»** (R-09) - считается в M4 и M5 по журналу и git-истории.

## Сознательно не делаем

- **Не вызываем модели из кода.** Вся работа ИИ - в чате; сервер только проверяет, пишет и отдаёт данные.
- **Не принимаем карточки без человека.** Нет режима «записать всех кандидатов сразу»: `add_cards` без `dryRun` вызывается после отбора.
- **Не перезаписываем пользовательский текст молча.** Слияние при импорте в существующую тему добавляет, а не заменяет секции.
- **Один сервер - один контент-репозиторий.** Без нескольких корней и без переключения репозитория на лету.
- **Не делаем свою систему плагинов инструментов.** Набор инструментов фиксирован таблицей в mcp-tools.
