- **Владелец:** Vladi Makarevich

## Кратко

Вторая кодовая веха: stdio MCP-сервер `wastech-learn-mcp` с инструментами контента и квиза, skills `learn-capture`, `learn-import`, `learn-quiz`, hook и промпт learning package. Разговор в Claude Code или ChatGPT превращается в проверенные файлы темы, а повторение идёт прямо в чате с записью в журнал. Строится на ядре M2; запись безопасна: проверка до записи, атомарность, идемпотентность по `requestId`. Работа разбита на 11 фаз.

## Как ведётся спека

Спека собирается skill `spec-task`: по одному документу, сначала основа, план последним, каждый документ согласуется с владельцем. Согласованный `plan/index.md` передаётся в реализацию через skill `implement`.
