# Критерии приёмки — M3, захват

[⌂ index](index.md) · требования — [requirements.md](requirements.md) · дизайн — [design.md](design.md)

Проверка автоматическим тестом, если не сказано иное. «Копия» — временная копия golden sample; «контракт» — тест инструмента через клиент MCP SDK в том же процессе.

## Функции

| # | Дано → когда → тогда | Проверка |
| --- | --- | --- |
| AC-F01 | Сервер запущен с `--content` на копии → клиент запрашивает список → все инструменты mcp-tools и `archive_package` на месте; неизвестный инструмент → `{ code, message, hint }` | контракт |
| AC-F02a | `create_topic` с `familiarity`, `keyIdea`, `pretest[]` → создан `index.md`, который проходит разбор M2, mdlint и `check` | контракт |
| AC-F02b | `add_cards` с тремя карточками → три файла с новыми уникальными `id`, `## Cards` в `index.md` дополнен; статус как во входе | контракт |
| AC-F02c | `update_card` с `meaningChanged: true` → старая карточка `retired`, новая с новым `id`; без флага — правка на месте, `id` тот же | контракт |
| AC-F02d | `save_summary` и `save_materials` → файлы по шаблону, разбор туда-обратно без потерь | контракт + unit |
| AC-F03a | `add_cards` с ответом длиннее лимита → находка `check`, на диске ничего не изменилось | контракт |
| AC-F03b | `validate` с черновиком, у которого дубль `id` в репозитории → находка уникальности (проверка с наложением) | контракт |
| AC-F04a | `add_cards` с `dryRun: true` → находки и будущие пути, файлов нет | контракт |
| AC-F04b | Тот же вызов с тем же `requestId` дважды, в том числе после перезапуска сервера → один набор файлов, одинаковые ответы | контракт |
| AC-F04c | Тот же `requestId` с другим входом → `REQUEST_ID_REUSED` | контракт |
| AC-F05 | `save_diagram` с валидным Mermaid и `alt` → `.mmd` и SVG с верным маркером; с синтаксической ошибкой или без `alt` → находка, файлов нет | контракт с подставным рендерером; сквозной — при `WASTECH_RENDER_E2E=1` |
| AC-F06 | `search` по словам вопроса существующей карточки → она первая в выдаче; фильтр по домену и статусу работает; польское слово находится и без диакритики | контракт |
| AC-F07a | Пакет из примера в learning-package в `inbox/` → `import_package` → тема и кандидаты, файлы не изменились | контракт |
| AC-F07b | Пакет с ошибкой front matter → находки с полем | unit |
| AC-F07c | `archive_package` → файл в `inbox/done/`, повтор с тем же `requestId` — без ошибки и без второго переноса | контракт |
| AC-F07d | Промпт экспорта на en, ru, pl требует одинаковые поля и секции | unit сравнения шаблонов |
| AC-F08a | `quiz_next(limit 5)` → не больше 5 review items, в ответе нет текста Answer, рубрики и объяснения | контракт |
| AC-F08b | `reveal` → ответ, рубрика, объяснение, `contentHash` | контракт |
| AC-F08c | `record_review` → строка в `reviews/<device>/mcp-YYYY-MM.jsonl` по схеме v1 с `grader`, `aiSuggested`, `confidence`; в ответе следующий due совпадает с replay M2 | контракт |
| AC-F08d | Оценка, после которой `lapses = leechThreshold` → в журнале ещё и `suspend`; карточка пропадает из `quiz_next` | контракт |
| AC-F08e | `undo_last` → событие `undo`; review item возвращается в очередь с прежним состоянием | контракт |
| AC-F09 | Три skill проходят mdlint корпуса; у каждого есть триггеры, шаги, «Done when», «What not to do» | lint + ревью |
| AC-F10 | JSON события `Edit` по файлу карточки с нарушением на stdin → `hook post-tool-use` пишет находку в stderr, код `2`; путь вне `content/**` → код `0` без проверки | CLI-тест |
| AC-F11 | `new-id` выдаёт 8 символов Crockford base32 нижнего регистра; генератор с одним сидом детерминирован | unit + CLI |
| AC-F12 | В контенте `npx --no-install wastech-learn-mcp --content .` стартует, Claude Code видит инструменты, hook срабатывает на правку | вручную |

## Качества

| # | Дано → когда → тогда | Проверка |
| --- | --- | --- |
| AC-N01 | Тесты сервера идут с запрещённой сетью; в коде нет HTTP-клиентов и вызовов моделей | тест + ревью |
| AC-N02 | Пути `../x`, абсолютный путь и символическая ссылка наружу → `PATH_OUTSIDE_CONTENT`, ничего не прочитано и не записано | контракт |
| AC-N03 | Ответы мутирующих инструментов на golden не длиннее 2 KB и не содержат текста файлов | контракт |
| AC-N04 | Сбой на третьем переименовании из пяти → все пять файлов в прежнем состоянии, временных файлов не осталось | unit с подменой ФС |
| AC-N05 | Для каждого инструмента есть контрактный тест | ревью |
| AC-N06 | Реальная тема из Claude Code: от «разберём X» до мини-квиза без учёта диалога ≤15 минут; итог — summary, материалы, ≥1 диаграмма, 5–12 карточек, 0 ошибок `lint` и `check` | вручную, замер в журнале изменений спеки |
| AC-N07 | `uiLanguage: pl` → находки в ответах инструментов на польском | контракт |
